# Skill: React Component Architect

## 用途

本 Skill 用于指导 AI 在开发 React 页面前，先设计组件拆分方案。

## 触发场景

当任务涉及新增页面、修改页面、重构页面结构、抽取通用组件、减少重复代码时，必须使用本 Skill。

## 必须读取

1. `docs/UI_COMPONENT_CATALOG.md`
2. `docs/COMPONENT_AND_MODULE_RULES.md`
3. `docs/CODE_COMMENT_RULES.md`

## 输出格式

```md
## 组件拆分方案

### 页面职责

### 页面专属组件

| 组件 | 目录 | 职责 |
|---|---|---|

### 可复用组件

| 组件 | 是否已有 | 建议目录 | 说明 |
|---|---|---|---|

### Hooks

| Hook | 职责 |
|---|---|

### API 封装

| 文件 | 接口 |
|---|---|

### 类型文件

| 文件 | 类型 |
|---|---|

### 不建议封装的内容

### 风险点
```

## 禁止事项

1. 页面写成巨型文件。
2. API 请求直接写在页面中。
3. 类型散落在多个页面。
4. 把业务组件错误放入 common。
5. 过度抽象一次性 UI。
6. 复制 `old-system/` 代码。
