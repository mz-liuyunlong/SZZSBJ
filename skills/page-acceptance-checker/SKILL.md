# Skill: Page Acceptance Checker

## 用途

本 Skill 用于检查一个页面是否真的完成，而不是只有页面壳子。

## 必须读取

1. `docs/PAGE_DEVELOPMENT_CHECKLIST.md`
2. `docs/ACCEPTANCE_CRITERIA_RULES.md`
3. `docs/TESTING_RULES.md`

## 输出格式

```md
## 页面验收报告

### 页面基础
### UI 状态
### API 与数据
### 组件拆分
### 权限与日志
### 测试结果
### 未完成项
### 风险点
```

## 强制规则

1. 必须逐条检查。
2. 不能用“基本完成”替代明确结果。
3. 未测试必须说明原因。
