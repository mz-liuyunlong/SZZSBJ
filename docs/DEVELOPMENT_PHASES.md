# 开发阶段规划

## 文件用途

本文件用于规定新系统从零建设的阶段顺序。AI 不允许跳过当前阶段，一次性生成大量未来模块。

## 阶段划分

| 阶段 | 目标 | 说明 |
|---|---|---|
| Phase 0 | 项目规则与 Git 规范 | 建立 AGENTS、docs、GitHub 模板、CODEOWNERS |
| Phase 1 | 前后端脚手架 | 创建 React/Vite 前端和 FastAPI 后端基础骨架 |
| Phase 2 | 基础工程能力 | 路由、布局、配置、日志、错误处理、API Client |
| Phase 3 | 基础数据能力 | 数据库连接、Alembic、基础表、任务表、操作日志 |
| Phase 4 | old-system 只读分析 | 输出功能清单、接口清单、数据流、新旧映射 |
| Phase 5 | 第一个业务页面闭环 | 选择一个页面，完成最小前后端闭环 |
| Phase 6 | 按功能切片逐个开发 | 一个功能一个页面、一个任务一个 PR |
| Phase 7 | 后台任务与 AI 能力 | 引入 Celery 任务、AI 调用适配层、安全审核流程 |

## 禁止

AI 不允许在早期阶段一次性生成所有菜单、所有页面、所有模型和所有接口。
