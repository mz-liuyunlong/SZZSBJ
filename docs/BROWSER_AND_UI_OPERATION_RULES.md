# Browser and UI Operation Rules

## Required Rules

- 浏览器/UI 自动化权限只限当前任务明确页面、账号、环境和动作。
- 页面可见不代表允许点击写操作；预览、表单提交、上传、删除、支付、部署和授权必须分别确认。
- 优先使用本地 fixture/mock；禁止用生产账号、生产数据或真实外部 API 做常规验收。
- 截图和录屏必须排除 secret、Cookie、个人信息和敏感业务字段。
- 自动化不得绕过登录、权限、验证码、二次确认或安全提示。
- 前端验收必须报告 URL/环境、步骤、结果和控制台错误；不能用截图替代测试。

## Stop Conditions

当前环境、动作副作用、账号权限或数据敏感性不明确时停止，不猜测点击。
