# 页面开发检查清单

## 文件用途

本文件用于每次开发一个页面时给 AI 做检查，避免页面只有空壳。

## 页面基础

- [ ] 页面名称明确。
- [ ] 所属模块明确。
- [ ] 路由明确。
- [ ] 菜单位置明确。
- [ ] 权限 key 明确。

## UI 与交互

- [ ] 页面标题正确。
- [ ] 筛选区完整。
- [ ] 表格或主内容区完整。
- [ ] 分页可用。
- [ ] Loading 状态完整。
- [ ] Empty 状态完整。
- [ ] Error 状态完整。
- [ ] 权限不足状态完整。

## 前端工程

- [ ] 页面没有写成巨型文件。
- [ ] 页面专属组件已拆分。
- [ ] 可复用组件已复用或登记。
- [ ] API client 已封装。
- [ ] types.ts 已定义。
- [ ] constants.ts 已抽取必要常量。
- [ ] 没有到处使用 any。

## 后端工程

- [ ] API 契约已确认。
- [ ] Route 保持薄。
- [ ] Service 写业务逻辑。
- [ ] Repository 写数据库访问。
- [ ] Pydantic Schema 完整。
- [ ] 数据库变更已确认。

## 安全与数据

- [ ] 数据来源明确。
- [ ] 字段血缘明确。
- [ ] 金额口径明确。
- [ ] 时间时区明确。
- [ ] 敏感操作有权限和日志。
- [ ] 没有修改 old-system。
