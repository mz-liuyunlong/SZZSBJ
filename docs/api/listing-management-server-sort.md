# Listing 全量排序（原版表头）

沿用现有 Listing 列表、批量搜索、精确筛选查询和 CSV 导出接口及现有权限与账号范围。新增可选 `sort_by` 字符串：按逗号分隔 `field:asc` 或 `field:desc`，按用户选择顺序定义优先级；字段仅允许 `LISTING_SORT_FIELDS` 中的 20 个键，拒绝重复键和非法方向。GET 使用查询参数，POST 使用 `query.sort_by`。不传或清空时恢复 WFS 库存降序、店铺、SKU、Item ID、唯一 ID 稳定排序。

后端先执行现有权限、业务筛选和统计卡片条件，再执行排序，最后分页。CSV 复用相同排序（保留现有导出数量上限）。数值按真实数值，日期按现有日期字段，状态按显式业务优先级；NULL 和未确认状态最后。SKU/MSKU 是复合排序；等级升序 A→D，生命周期升序风险优先。购物车缺货不是异常，排序排在异常与正常之间；无库存 Listing 与未确认不参与异常排名。生命周期使用数据库正式状态，不使用本地临时预览候选。

表头使用现有 Ant Design 排序箭头；升序、降序、取消三态。跨列选择保留优先级；顶部重置清除排序。修改排序自动回到第一页，仅刷新列表，不刷新统计或选项。翻页、筛选与导出保留排序。隐藏正在排序的列时清除该列条件。

不增加新 API 地址或数据库结构，不改变业务规则、权限、表格视觉样式。验收需覆盖 20 字段两种方向、跨页与导出、空值、组合排序、取消及重置、原版表格/虚拟滚动和接口请求次数。
