# ADR：架构决策记录

## 用途

重大技术选择必须写 ADR，防止未来开发者或 AI 重复争论已确定的决策。

## 文件命名

```text
0001-use-react-vite-ant-design.md
0002-use-fastapi-sqlalchemy-alembic.md
0003-use-celery-for-background-tasks.md
0004-old-system-readonly-reference.md
```

## 模板

```md
# ADR 0001: 标题

## 状态

Accepted / Proposed / Deprecated

## 背景

## 决策

## 影响

## 替代方案

## 备注
```
