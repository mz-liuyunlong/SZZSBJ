# 时区与币种规则

## 文件用途

本文件用于约束时间和金额字段，避免美国平台时间、中国/台湾本地时间、数据库时间混用。

## 时间规则

需要明确：

- 数据库存储时区。
- 平台原始时间时区。
- 前端展示时区。
- 报表统计时区。
- 日期筛选按哪个时区。

建议默认：数据库存 UTC，保留平台原始时间字段，前端按业务确认的时区展示。

## 币种规则

金额字段必须带币种后缀，例如：

```text
sales_amount_usd
settlement_amount_usd
cost_cny
refund_amount_usd
ad_spend_usd
```

## 汇率规则

如涉及 USD / CNY 换算，必须说明：

- 汇率来源。
- 汇率日期。
- 是否固定月汇率。
- 是否允许手动调整。
- 换算后字段名称。
