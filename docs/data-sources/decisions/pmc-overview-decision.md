## 3. 数据血缘（核心字段）

| 字段 | 来源 | 计算 |
|---|---|---|
| 全链路有效供应 | O1 | 各互斥段之和，不含海外仓 |
| 覆盖天数 | O1 | 有效供应 ÷ 日销；有库存天数 < 14 或日销 = 0 不算 |
| 已断货 | O1 | 日销 > 0 且 WFS 可售 < 5（instockMin） |
| 断货风险 | O1 | 时间线有断货窗口，或无来货且提前期内卖完；已断货的不重复计 |
| 供应链异常 | O1 + O6 + O8 | 已过预计可售日未上架 / 超期无物流轨迹（海外仓发出不套）/ 被查验 / 采购已下单未到货超期 / 缺默认箱规 |
| 执行异常 | O8 + O5 | 采购计划待审批 > 2 天 / 待采购、待下单 > 7 天 / 惠州在仓 > 7 天且合计 ≥ 10 件 |
| 海外仓可补 | O9 + O1 | 同 SKU 海外仓件数按断货最早的 ItemID 先分，分到 min(剩余, 建议量) |
| 主要问题 | O13 | = 全部提示的第一条，提示顺序：产品标签 > Listing 异常 > 已断货 > 断货风险 > 供应链异常各条 > 执行异常各条 > 严重过剩 > 库存过剩 > 滞销 > 尾货 / 近 90 天无库存 > 有库存天数不足 > 海外仓可补 > 单次封顶 |
| 主表排序 | O13 | 分类优先级：Listing 异常 > 已断货 > 断货风险 > 供应链异常 > 执行异常 > 严重过剩 > 库存过剩 > 滞销 > 海外仓可补 > 近 90 天无库存 > 有库存不足 30 天 > 正常；同级按能卖到日期升序，再按有效供应降序 |
