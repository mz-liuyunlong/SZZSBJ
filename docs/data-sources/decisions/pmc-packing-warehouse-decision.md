# 仓库打包数据源与规则决策（2026-10-21）

本轮负责人授权当前dev、本地127.0.0.1:55432/LOCAL_DATABASE_NAME，业务接口与本地模拟联调。无新分支、无提交推送、无生产操作。PMC静态分组导航及已移除的双轨对账/通知设置菜单保持现状。

## 业务权威

PK为新系统单据本体，替代备货单；仓库不核对领星备货单数量/状态。审批Q、商品及来源快照以PackingOrder为准。实际装箱T以BoxSet/Lines为准。一张PK完成一次，之后只走带原因的改装箱，保留首次完成时间及不可变事件中的前后明细。

到仓日期=批次看板入库业务日（北京时间），实际收货日按可靠DWD关联另列，不按PO×SKU猜测。尺寸/单品毛重不全或匹配未知，须仓库补填本单测量快照，不改产品主数据。

## 余量与事务

负责人已确认库存100、当前Q80、其他占用0时额外余量20。预算同账号/惠州仓/同SKU，跨全部入库单；减当前原审批占用、其他有效原分配及额外分配。改装箱重判只排除本PK的旧额外占用，不能漏扣原Q。未知库存不是0，不生成虚假缺口。

所有库存命令使用与发布器/审批相同的账号+仓库advisory事务锁，先锁此范围再锁PK；原审批数量保持，额外占用逐来源MART复合FK记录，审批可发余额共用预算并扣减。消失或超额的来源占用继续计入总预算，防止换发布版本后凭空释放。

## 完成、异常和处置

- T=Q：资料有效后完成。
- T<Q：必选实物短少/破损/装不下箱/其他；其他须说明。完成后未装量待中台处置，不自动重出PK；下次再发才减少有效原占用并回池，作废未装须原因且保留排除占用，不伪造领星核销。
- T>Q且E<=额外余量：显式确认后原子占用，完成至已打包待发。
- T>Q且E>余量：必填原因，原子记录缺口G、blocked异常及本地待通知任务，返回command_outcome=blocked，不伪报完成。重复同异常不重复通知。
- 阻塞时仓库可改箱，E落回允许范围后ready/resolved并取消待通知任务；仍须人工点击完成。已完成单改装箱如库存不足，只保存提议，不覆盖原实装，补齐或修正后再次改装箱。

中台登记IB与同步为独立动作。同步须校验可信新发布版本的账号/仓库/SKU/IB、入库数量>=G及最新预算；不足返回差量，匹配后只变ready，不自动完成。parent入库数量跨店铺重复，不能直接相加。登记、同步成功/失败/未配置、原因、解除均写不可变PK事件。

## 当前交付边界

业务接口/页面、跨IB额外占用、异常卡片、中台登记IB、模拟同步核验、outbox、幂等与真实并发事务已本地验证。同步provider是受信任服务端依赖，HTTP请求不能注入证据。正式本地服务默认未配置真实领星同步，返回LINGXING_SYNC_NOT_CONFIGURED并留痕；仅隔离联调进程覆盖该依赖生成合成发布版本，测试结束全部回滚。没有真实领星拉取、领星写入、货件创建、箱规回写或飞书/钉钉发送。

复用现有IAM，操作人取登录身份。仓库仅装箱/改装箱/完成；中台登记IB/同步/未装处置/延迟备注分别授权。只新增权限定义，不修改现有用户或角色授权。
