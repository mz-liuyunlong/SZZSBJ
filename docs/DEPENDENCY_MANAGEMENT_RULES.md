# 依赖管理规则

## 文件用途

本文件用于约束 AI 如何新增、删除和更新依赖。

## 未确认项

以下内容需要项目负责人确认，AI 不允许自行决定：

- 前端包管理器：npm / pnpm / yarn。
- 后端依赖管理：uv / Poetry / requirements.txt。
- Node 版本。
- Python 版本。

## 新增依赖前必须说明

1. 为什么现有依赖不能解决。
2. 新依赖解决什么问题。
3. 是否有长期维护。
4. 是否影响构建体积。
5. 是否有安全风险。
6. 是否有更轻量替代方案。
7. 是否会引入第二套架构。

## 禁止

1. 不能混用 npm / pnpm / yarn。
2. 不能混用 requirements / poetry / uv。
3. 不能为一个小功能引入大型库。
4. 不能新增与固定技术栈冲突的依赖。
5. 不能在未确认情况下升级核心依赖大版本。
