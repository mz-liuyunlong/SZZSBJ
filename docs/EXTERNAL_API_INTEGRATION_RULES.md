# 外部 API 接入规则

## 文件用途

本文件用于约束 Walmart、Amazon、领星、Decodo、紫鸟、OpenAI 等外部 API 的接入方式。

## 总原则

1. 外部 API 客户端必须放在 `backend/app/integrations/`。
2. 前端不直接调用敏感外部 API。
3. 认证、超时、重试、错误转换必须统一封装。
4. 日志不能输出 Token、Cookie、完整请求头、完整密钥。
5. 批量调用必须走 Celery。
6. 外部 API 返回必须标准化后再进入 Service。

## 客户端设计要求

每个外部 API Client 必须说明：

- API 来源。
- 认证方式。
- 超时时间。
- 重试策略。
- 限流策略。
- 错误码映射。
- 响应标准化结构。
- 是否可能产生费用。

## 禁止

1. 在 Route 中直接写外部 API 请求。
2. 在 React 页面中直接请求外部平台 API。
3. 到处散落同一个 API 的请求代码。
4. 批量请求不做限流和重试控制。
