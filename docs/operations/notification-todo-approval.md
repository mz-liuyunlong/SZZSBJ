# 通知、待办、审批规则

## 1. 通知中心

重要事件必须进入通知中心：

```text
数据同步失败
库存预警
广告异常
Listing 异常
WFS 费用异常
权限变更
审批待处理
导入失败
AI 任务完成
历史重算完成
```

通知必须支持已读/未读、跳转相关页面、处理状态。

## 2. 待办闭环

异常不能只提示，必须可追踪处理结果。

待办字段：

```text
负责人
截止时间
状态
处理备注
关联对象
关联页面
```

状态：

```text
待处理
处理中
已解决
已忽略
已关闭
```

## 3. 审批流

高危动作必须先生成审批单。

对象：

```text
费用规则修改
权限变更
历史重算
批量导入
批量删除
AI 建议落库
利润公式调整
```

状态：

```text
draft
submitted
approved
rejected
cancelled
executed
failed
```

审批和执行必须分离，审批记录不可删除。
