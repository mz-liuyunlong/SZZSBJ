# 发布、回滚、备份规则

## 1. 发布前必须具备

```text
CI 通过
数据库迁移已审核
API 文档已更新
SOP 已更新
回滚方案已写明
影响范围已说明
```

## 2. 回滚规则

```text
前端回滚到上一个 build
后端回滚到上一个镜像/版本
数据库 migration 必须有降级方案或补偿方案
Feature flag 可快速关闭新功能
```

## 3. 备份规则

```text
新 PostgreSQL 必须每日备份
生产库迁移前必须确认可回滚
重要表迁移前必须备份
每月至少做一次恢复演练
备份不能只存在同一台服务器
```

## 4. 月结锁账

```text
已月结数据默认锁定
锁定月份不允许普通重算
历史修正必须走审批
重算必须生成批次号
重算前必须预览影响金额
重算后必须保留旧结果和新结果差异
```
