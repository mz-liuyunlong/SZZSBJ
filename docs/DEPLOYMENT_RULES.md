# 部署规则

## 文件用途

本文件是部署规则模板。具体部署方式未确认前，AI 不允许自行生成生产部署方案并执行。

## 待确认部署方式

- 前端部署：Vercel / 服务器 / Docker / 其他。
- 后端部署：服务器 / Docker / 云服务 / 其他。
- 数据库位置：云数据库 / 自建数据库 / 其他。
- Redis 位置。
- Celery Worker 运行方式。
- 域名和 HTTPS。

## 规则

1. AI 不允许自行修改生产部署配置。
2. AI 不允许自行重启生产服务。
3. AI 不允许把本地配置当生产配置。
4. 所有部署配置必须脱敏。
5. 部署前必须有回滚方案。
