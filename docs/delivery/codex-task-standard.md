# Codex 任务标准

## 1. 任务粒度

```text
一个任务只做一个明确功能
一个任务最多一个页面或一个 API 模块
一个任务不能同时做导航、数据库、页面、权限、AI
一个任务结束必须交接
```

## 2. 任务模板

每个任务必须包含：

```text
任务名称
工作模式
允许修改范围
禁止事项
输入文件
输出文件
验收标准
需要运行的检查
完成报告格式
```

## 3. 开发前输出

AI 修改代码前必须输出：

```text
任务类型判断
准备读取哪些 docs / skills
为什么选择这些 docs / skills
哪些本次不需要
允许修改范围
禁止事项
开发计划
验收标准
```

## 4. 完成报告

```text
## Done
完成了什么

## Files changed
修改了哪些文件

## Commands run
运行了哪些命令

## Tests run
测试结果

## Risk check
是否修改 old-system
是否连接数据库
是否改 .env
是否调用外部 API
是否影响权限
是否影响数据库迁移

## Acceptance checklist
按任务验收项逐条打勾

## Next step
下一步建议
```

如果没有运行测试，必须说明原因。
