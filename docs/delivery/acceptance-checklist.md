# 功能验收清单

## 1. 页面验收

```text
页面能打开
页面状态正确
权限控制正确
数据范围显示正确
空数据状态正确
错误提示正确
加载状态正确
分页可用
筛选可用
排序可用
右上角帮助入口可用
SOP 可打开
Playwright 页面验收通过
```

## 2. API 验收

```text
返回统一格式
有 request_id
有 response_model
有错误码
有权限校验
有数据权限过滤
有 source / source_tables
OpenAPI 可见
Markdown API 文档已更新
API 文档页面可见
```

## 3. 数据验收

```text
数据来源明确
数据最新时间明确
大表强制分页
旧库只读
无 SELECT * 扫描大 raw 表
金额口径明确
时间口径明确
```

## 4. 高危功能验收

```text
二次确认
审批流程，如适用
影响预览
审计日志
可回滚或补偿方案
不能直接改历史
```

## 5. 完成定义

```text
代码完成
测试通过
Playwright E2E 已补充或说明不适用
API文档完成
SOP完成
开发交接完成
验收清单通过
风险说明完整
```
