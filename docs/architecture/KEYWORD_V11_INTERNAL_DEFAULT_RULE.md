# Walmart 关键词 V1.1 内部分析默认规则

## 生效与来源

`20261025_0058_keyword_internal_default` 在已有关键词表上安装固定 ID 的全局 `scoring` 规则集和版本 1。迁移重复执行不新增版本；已存在但 ID、状态或配置哈希不一致时中止。运行时只读选择生效规则：优先当前账户已启用、已发布的版本；没有账户版本时使用系统全局基线。前端 `initialRules` 仅供本地预览，不作为分析版本或评分来源。新 Run 保存实际 `rule_version_id`、输入哈希和冻结结果；历史 Run 不因新版本发布而重算。

默认权重为商品相关性 30、搜索意图 20、Walmart 页面承接 20、词根 15、市场数据 15；风险为独立扣分及硬门禁。P0/P1/P2 为 85/75/60，内部候选名额为 5/10/30，Exact 最多 20，Broad 最多 5 个词根及 15 个长尾。来源为已锁定 V1.0 规则和 `WALMART_KEYWORD_V11_RULES.md` 的安全工程基线。前端历史字段 `coverage` 对应后端的 Walmart `page` 分量，不能把 ASIN 覆盖当成 Walmart 页面承接证据。

系统规则只授权**内部分析和人工复核**。没有已核验市场口径时，数据分量仍为空，关键词进入人工复核；不填造市场分、风险词、品牌证据或页面埋词。默认 Bid、Budget、广告启动日期、广告命名均未配置；系统规则不授权 Walmart 正式广告上传、创建或调价。页面的模拟出价是本地旧示例，不得进入生产分析规则。

## 管理员变更与待决政策

管理员可用现有 RBAC 保护的规则集、草稿和保存接口形成账户版本；默认全局规则不可直接编辑。服务端当前的 `publish_scoring_rule()` 仍要求 D01–D08 独立复核及不同发布人，见 `KEYWORD_V11_RULE_DECISIONS.md`。负责人希望改为原有 RBAC 单人管理，但该安全策略的正式例外尚未落地，因此**账户自定义草稿发布状态为 `POLICY_DECISION_REQUIRED`**。本次不移除门禁；这不妨碍普通运营使用系统默认版本进行内部分析。未来获批的账户新版本只对新 Run 生效。

## 验证与发布边界

本变更新增数据迁移，合并代码不等于生产已安装默认规则。生产迁移和部署需要独立授权。本地隔离 PostgreSQL 测试覆盖安装幂等、无账户规则时读取默认版本、账户版本优先、内部分析持久化及历史 Run 版本不变。
