# 工程架构规则目录

本目录用于定义 SKYC V2 的工程架构。AI 开发前必须按任务类型读取对应文件。

| 文件 | 用途 |
|---|---|
| `frontend.md` | 前端框架、目录、PageShell、navigation.ts、帮助入口 |
| `backend.md` | FastAPI 分层、模块目录、service/repository/schema/task |
| `database.md` | PostgreSQL 分层、旧库只读、新库初始表 |
| `api.md` | API 返回格式、分页、OpenAPI、错误码 |
| `security-secrets-integrations.md` | Token、飞书群、Webhook、外部集成安全规则 |
