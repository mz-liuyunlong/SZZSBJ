# 业务词典

## 文件用途

本文件用于统一项目中的业务词汇定义，避免 AI 自行理解导致字段、页面、接口含义混乱。

| 词汇 | 定义 | 注意事项 |
|---|---|---|
| SKU | 商品库存单位 | 需要区分平台 SKU、商家 SKU |
| MSKU | 店铺维度下用于销售和库存管理的商家 SKU | 同一产品不同店铺可能不同 MSKU |
| Item ID | 平台商品 ID | 不等于系统内部产品 ID |
| 店铺 | 平台账号或销售店铺 | 所有报表通常需要按店铺过滤 |
| 平台订单号 | Walmart / Amazon / TEMU 后台订单 ID | 不得与系统内部订单 ID 混用 |
| 供货价 | 商品采购或内部供货成本 | 需明确币种 |
| 回款 | 平台结算后实际回收金额 | 和销售额不同 |
| 利润 | 收入扣除成本、物流、退款、广告等后的结果 | 必须明确计算口径 |
| 退款 | 客户退款金额 | 不等于退货 |
| 退货 | 客户退回商品行为 | 可能产生退货运费 |
| 广告活动 | 平台广告 Campaign | 与关键词、搜索词、预算相关 |
| 关键词 | 主动投放词 | 与搜索词不同 |
| 搜索词 | 用户实际搜索词 | 用于否定词和优化 |
| WFS | Walmart Fulfillment Services | 与仓储、配送、库存费用相关 |

AI 遇到未定义的业务词汇，不允许自行猜测，必须先询问或标记“待确认”。
