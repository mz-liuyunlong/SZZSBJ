# 项目初始化规则

## 文件用途

本文件用于约束 AI 在空白新项目中如何搭建基础工程骨架。

## 初始化原则

1. 先搭工程骨架，再做业务页面。
2. 先建立目录规范，再写具体模块。
3. 先建立 API / 错误 / 配置 / 日志 / 数据库基础能力。
4. 先建立通用组件和模块清单，再逐步实现。
5. 不允许一次性生成完整业务系统。

## 推荐初始化顺序

1. 创建 `frontend/` 和 `backend/` 目录。
2. 初始化前端 Vite React TS 项目。
3. 初始化后端 FastAPI 项目。
4. 建立基础配置与环境变量模板。
5. 建立统一 API Client。
6. 建立统一错误处理结构。
7. 建立数据库连接与 Alembic。
8. 建立基础任务表与操作日志表设计草案。
9. 建立前端布局、路由和菜单骨架。
10. 建立第一个示例页面闭环。

## 不允许 AI 一次性生成

- 全部业务模块页面
- 全部数据库表
- 完整权限系统
- 全部 Celery 任务
- 完整 AI 中心
- 完整 old-system 功能重建实现

AI 必须小步推进，每一步都能审查和回滚。
