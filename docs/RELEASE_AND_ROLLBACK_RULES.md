# 发布与回滚规则

## 文件用途

本文件用于约束 dev/main 分支、发布前检查和问题回滚方式。

## 分支建议

- `dev`：日常集成分支。
- `main`：稳定生产分支。
- `ai/*`：AI 开发任务分支。
- `feature/*`：人工或混合开发功能分支。

## 发布前检查

1. PR 已审核。
2. CI 通过。
3. 数据库 migration 已审查。
4. 环境变量已确认。
5. 敏感操作已确认。
6. 回滚方案已写明。
7. 关键页面已人工验收。

## 回滚规则

代码回滚优先使用：

```bash
git revert <commit-id>
```

数据库 migration 回滚必须单独确认，不允许 AI 自动回滚生产数据库。
