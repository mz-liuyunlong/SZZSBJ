# 验收标准规则

## 文件用途

本文件用于约束 AI 在开发前后如何定义和检查验收标准。

## 开发前

AI 必须先输出验收标准。没有验收标准，不允许直接说“开发完成”。

## 开发后

AI 必须逐条对照验收标准说明：已完成、未完成、部分完成、需要用户确认。

## 列表页验收示例

1. 页面路由可访问。
2. 页面标题正确。
3. 筛选区完整。
4. 表格字段完整。
5. 分页可用。
6. Loading / Empty / Error 状态完整。
7. API client 已封装。
8. TypeScript 类型完整。
9. 没有写死真实数据。
10. 没有修改 `old-system/`。
11. 没有复制旧代码。
12. 必要注释已补充。
