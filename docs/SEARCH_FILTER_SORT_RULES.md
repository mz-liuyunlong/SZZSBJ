# 搜索、筛选、排序规则

## 文件用途

本文件用于统一列表页查询体验。

## 规则

1. 列表必须分页。
2. 默认筛选条件必须明确。
3. 日期范围默认值必须说明。
4. 排序字段必须白名单，不能直接信任前端传入字段。
5. 模糊搜索范围必须明确，例如 SKU、MSKU、订单号。
6. 查询条件命名必须与 API 契约一致。
7. 是否保存用户上次筛选需要在页面需求中说明。
8. 大表查询必须要求店铺和日期范围。

## 推荐参数

```text
page
page_size
sort_by
sort_order
keyword
store_id
date_from
date_to
```
