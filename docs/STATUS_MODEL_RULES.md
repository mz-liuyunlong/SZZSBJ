# 状态模型规则

## 文件用途

本文件用于约束任务、订单、退款、广告、库存等业务状态的命名、展示和流转。

## 总原则

1. 状态必须枚举化。
2. 状态不能用随意字符串。
3. 前后端不能各定义一套状态。
4. 状态展示颜色要统一。
5. 状态流转需要说明。
6. 状态变更如属于敏感操作，需要操作日志。

## 后台任务状态

```text
pending
running
succeeded
failed
cancelled
partial_success
```

## 状态定义模板

| 状态 | 含义 | 是否终态 | 展示颜色 | 可流转到 |
|---|---|---|---|---|
| pending | 待处理 | 否 | default | running/cancelled |
