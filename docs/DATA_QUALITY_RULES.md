# 数据质量规则

## 文件用途

本文件用于约束 AI 如何处理同步、导入、计算中的异常数据。

## 常见数据质量问题

- 字段为空
- 重复订单
- 重复 SKU
- 金额为负
- 时间格式错误
- 店铺匹配不到
- 平台返回异常
- 导入文件少列
- 退款和订单无法匹配
- 广告数据与订单数据时间口径不一致

## 处理策略

AI 设计数据功能时必须说明：

1. 哪些错误阻断任务。
2. 哪些错误跳过并记录。
3. 哪些错误允许部分成功。
4. 是否生成错误明细。
5. 用户如何下载错误报告。
6. 是否需要人工修正。
7. 是否影响财务计算。

## 状态建议

```text
valid
warning
invalid
skipped
duplicate
unmatched
```

## 禁止

AI 不允许静默丢弃异常数据，也不允许把异常数据当正常数据参与财务计算。
