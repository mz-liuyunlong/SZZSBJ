# 文档更新规则

## 文件用途

本文件用于约束 AI 在新增功能后同步更新项目文档。

## 规则

新增页面时，AI 应更新：

- 路由 / 菜单说明
- API 契约
- 组件清单，如新增 Shared 组件

新增后端模块时，AI 应更新：

- 后端模块清单
- API 契约
- 数据库说明，如新增表

新增 Celery 任务时，AI 应更新：

- 后台任务开发文档或任务清单
- 任务状态说明

新增重大架构决策时，AI 应新增 ADR：

```text
docs/adr/YYYYMMDD-title.md
```

## 禁止

AI 不允许只改代码不更新相关文档，除非用户明确说明本次只做临时实验。
