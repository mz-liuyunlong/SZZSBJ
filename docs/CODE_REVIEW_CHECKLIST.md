# Code Review 检查清单

## 单功能确认

- [ ] 本 PR 只处理一个功能。
- [ ] 本 PR 最多只新增或修改一个页面。
- [ ] 没有顺手开发其他模块。
- [ ] 没有大范围重构。

## old-system 确认

- [ ] 没有修改 `old-system/`。
- [ ] 没有从 `old-system/` 直接复制代码。
- [ ] 如参考了 `old-system/`，已说明读取了哪些文件。
- [ ] 如参考了 `old-system/`，已提炼业务规则并重新设计。

## 技术栈确认

- [ ] 没有引入第二套前端框架。
- [ ] 没有引入第二套 UI 框架。
- [ ] 没有引入第二套后端框架。
- [ ] 没有引入第二套后台任务系统。
- [ ] 没有未经确认新增依赖。

## 封装确认

- [ ] 页面没有写成巨型文件。
- [ ] API 请求已封装。
- [ ] 类型定义清晰。
- [ ] 后端按 Route / Schema / Service / Repository 分层。
- [ ] Celery Task 没有堆复杂业务逻辑。

## 安全确认

- [ ] 没有提交密钥。
- [ ] 没有修改生产配置。
- [ ] 敏感操作有权限和操作日志。

## 测试确认

- [ ] 已执行相关测试或说明无法执行原因。
- [ ] 验收标准逐条对照。
