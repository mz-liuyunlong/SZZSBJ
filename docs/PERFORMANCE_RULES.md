# 性能规则

## 文件用途

本文件用于避免 AI 写出对大数据量不友好的代码。

## 总原则

1. 列表必须分页。
2. 禁止一次性查询全表。
3. 大表查询必须按店铺、日期等条件过滤。
4. 常用筛选字段应考虑索引。
5. 前端表格不要一次渲染上万行。
6. 复杂报表走后台任务。
7. 批量外部 API 请求必须限流。
8. 导出大文件必须走 Celery。

## 禁止示例

```python
rows = db.query(Order).all()
```

应改为分页和筛选查询。

## AI 输出要求

涉及大表、报表、同步、导入导出时，AI 必须说明性能风险和应对方式。
