# 数据血缘与数据质量规则

## 1. 数据血缘

每个 ready 页面必须能说明：

```text
页面 → API → service → repository → source table → 字段 → 计算公式
```

每个 API 文档必须写：

```text
source
source_tables
freshness
warnings
```

不能解释来源的数据，不允许进入财务 / 利润页面。

## 2. 数据新鲜度

每个核心数据源必须有 SLA：

```text
销售数据：每日更新
广告数据：每日更新
库存数据：每日更新
退款数据：每日更新
结算数据：按账期更新
WFS费用：按平台数据周期更新
```

页面必须显示数据最新时间。超过 SLA 未更新，必须提示数据过期。

## 3. 数据质量检查

核心检查项：

```text
最新业务日期
行数是否异常
金额是否异常
空字段比例是否异常
重复订单
SKU 映射失败
店铺映射失败
负责人缺失
```

异常数据不得静默丢弃，应进入隔离区。

## 4. 数据可信度等级

```text
official    官方同步数据
calculated  系统计算数据
manual      人工录入数据
ai          AI 生成建议
estimated   估算数据
unknown     未确认来源
```

AI 结果不能和官方数据混在一起展示，必须明确标识。
