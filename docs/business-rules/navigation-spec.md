# 本项目 导航规范

## 1. 导航原则

- 一级导航 = 左侧主菜单。
- 二级导航 = 左侧展开菜单 / 顶部模块入口。
- 括号内容 = 页面内部 Tab，不作为左侧菜单项展示。
- 所有导航只允许从 `frontend/src/config/navigation.ts` 生成。
- 除数据中心已增加 API文档外，不随意新增一级导航。
- 不新增独立后台管理系统，不新增系统管理一级菜单。

## 3. API 文档页面

API 文档固定在：

```text
数据中心 → API文档
```

权限点：

```text
data_center.api_docs.view
```

普通业务用户默认不可见。

## 4. 帮助文档入口

帮助文档不放左侧菜单。每个页面右上角固定 `?`，点击新标签页打开当前页面 SOP。

## 5. 页面状态

```text
planned       计划中
building      开发中
testing       测试中
ready         已完成
disabled      已停用
hidden        隐藏
```

只有 `ready` 页面才能给普通用户正式使用。


页面是否只读属于页面能力属性，必须使用 `readOnly: true/false` 表达，不得写成 `status: 'readonly'`。
`legacy`、`iframe`、`deprecated` 不属于页面开发状态，不得放入 `PageStatus`。
