# 采购与批次多ItemID查看说明

采购计划备注与采购明细备注合并检查；仅将同账号同店铺且本地SKU匹配的Listing身份作为备注归属。两种备注均有有效不同ItemID时保留全部，显示多listing（N）及各自GTIN/MSKU，不把多值等同冲突。无法校验的备注值不会冒充已确认归属。

采购看板可按任一个ItemID、GTIN或MSKU搜索对应原行。数量和金额仍属于原采购行，多值展示不表示每个身份各拥有整行数量；本次没有实现身份间数量分配。批次库存与打包审批流程也未调整。

无有效备注时显示同店铺SKU的Listing候选，来源为Listing匹配；采购备注来源页面统一显示采购备注。历史DWS需按原流程另行刷新后才出现新增集合；旧快照仍按原单值显示。不要为了补齐显示而直接改业务表。

2026-10-31 负责人决定（PO261016006 案例）：备注里的 ItemID 以店铺为准验证——同店铺 Listing 存在即采信，Listing 本地 SKU 为空或不同都不再阻断（不同时标 SKU 不一致）；无备注时 Listing 本地 SKU 为空的按采购明细 MSKU 匹配。采购看板与国内入库看板/打包单候选共用同一个规则函数（`pmc_purchase/item_id_resolution.py`，证据规则号 purchase.remark.store.v2）。
