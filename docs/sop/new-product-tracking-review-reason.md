# 打品跟踪人工判定复盘说明

- 适用入口：打品跟踪 → 打品详情 → 人工判定打品结果。
- 四种结果（打品成功、继续观察、需要优化、打品失败）均必须填写复盘说明 / 判定依据，至少 10 个非空白 Unicode 字符。空格、换行等不计入长度。
- 输入框显示必填标识与有效字符数，未达到最低长度或未选择合法结果时不能保存。后端 `TrackingWrite` 与 `NewProductService.save_tracking` 同时校验；绕过 UI 亦无法保存不合格原因。原有 4000 字符上限保持。
- 历史已保存结果和只读状态不补写、不重算、不解锁；原有账号范围、版本校验、WFS 首次可售门槛与最终结果锁定保持不变。
- 接口仍为 `PUT /api/new-products/tracking/decision`，使用原有 reason 字段、决策表及事件表；无新表、迁移、外部调用或任务。
- 验收：逐一选择四种结果，测试空内容、9 字、10 字及空白混入；确认历史最终结果仍可只读查看。
