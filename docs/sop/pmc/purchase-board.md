# 页面使用说明：采购看板

## 1. 功能位置

左侧导航 `PMC` → `采购看板`，路径 `/pmc/purchase-board`。页面右上角 `?` 帮助按钮打开本文。

## 2. 这个页面是干嘛的？

按"采购单明细 × 采购计划"逐行展示采购进度：处于哪个阶段、是否逾期、店铺与 ItemID 归属、收货进度、到仓日期、采购交期，以及 SKU 级的实际采购交期。它是采购单看板，**未转成采购单的采购计划不进主表**；已审批待采购的计划通过右上角"待采购计划"单独查看。

## 3. 谁需要使用？

采购、PMC / 中台、产品负责人、管理层。全员可看；人工修正交期（Gate 4b）需要单独权限。

## 4. 它有什么用？

- 一眼看到待到货、逾期未到货、待采购超时、本月采购金额、交期不稳定 SKU、ItemID 待处理七个数字，点卡片即筛选。
- 批量粘贴 SKU / ItemID / GTIN / MSKU / 采购单号查进度。
- 打开采购单详情看明细 × ItemID、收货单、计划链和近 5 单交期样本（被剔除样本灰显）。

## 5. 操作步骤

1. 用负责人 / 状态 / 下单日期 / 搜索框缩小范围；"更多筛选"里有 ItemID 归属、采购量、单价、WFS 就绪。
2. 搜索框先选类型，再输入（多个值用逗号或空格分隔）或点批量图标粘贴（一行一个，最多 200 个）。
3. 点统计卡片快速切到对应清单；再点一次取消。
4. "今日待跟进"开关只看已逾期或今日到期的行。
5. 点采购单号或"详情"打开采购单详情。
6. 右上角"待采购计划"查看已审批未转单的计划，可只看超时。
7. 列配置按钮调整显示列与顺序（仅保存在本浏览器）。

## 6. 字段说明

| 字段 | 含义 |
|---|---|
| 状态 | S2 待下单 / S3 已下单未到货 / S4 部分到货 / S9 已到货 / S0 已作废；红色标签为逾期天数，"待采购超时"与"逾期（到货）"分开计 |
| 店铺 | 领星店铺；`未归属店铺`（sid=0）不参与逾期 |
| ItemID | Walmart ItemID，点击新标签页打开商品页；无 ItemID 时显示归属状态（待打包单 / 待处理） |
| 进度 | 收货量 / 分配量（百分比） |
| 到仓日期 | 累计收货首次 ≥ 采购量 × 到仓比例（规则表，默认 50%）的收货单日期 |
| 采购交期 | 该单下单到到仓的天数；< 2 天标"已剔除"，不进 SKU 样本 |
| 审批周期 | 计划创建到下单的天数 |
| 实际采购交期 | SKU 级：近 5 单样本 / 基准 / 领星默认交期；"不稳定"= 样本极差超阈值 |
| 单价 / 金额 | 明细单价与按计划比例分配的金额，币种随采购单 |
| 计划号 | 该明细对应的采购计划（合并单可多张） |

## 7. 数据来源

后端只读接口 `/api/pmc/purchase/*`（`docs/api/pmc-purchase-api.md`），数据来自 DWS 表 `dws_purchase_board` / `dws_purchase_sku_cycle` / `dws_purchase_pending` 与 `dwd_purchase_plan`，由 Gate 3 刷新脚本生成；页面顶部显示"数据更新"时间与规则版本。负责人下拉来自产品管理。

## 8. 权限说明

查看：`pmc:purchase:read`。人工修正交期：`pmc:purchase:override`（本页暂未开放，Gate 4b）。无权限时页面显示提示，不显示任何数据。

## 9. 常见问题

- **没有数据？** 生产尚未执行 Gate 3 迁移 / 发布 / 刷新时表为空，属正常；等负责人授权执行后再看。
- **卡片和列表数字对不上？** 卡片按采购单去重，列表按明细 × 计划计行。
- **待采购超时为什么两个数？** 待下单采购单（S2）与已审批未转单计划分别统计。
- **店铺下拉在哪里？** 暂无店铺选项接口，本版未提供；可用搜索或状态"未归属店铺"。

## 10. 注意事项

- 本页无导出、无推送、无写操作；ItemID 人工归属功能已取消（负责人 2026-09-21）。
- 列配置只存在浏览器本地，换设备需重新设置。
