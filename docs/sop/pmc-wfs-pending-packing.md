# 待发货打包单使用说明

1. 在国内仓完成系统打包单审批、装箱和“打包完成”。未完成单只进入上方统计，不进下表。无需先补领星OWS；装箱只认本系统。
2. 按店铺、PK/SKU/ItemID/GTIN搜索。可选“只看测试单”；重置清除全部筛选。刷新重新查询，页面不使用示例数据补空。
3. 查看原审批数量与实际装箱数量；合法少装、多装按仓库规则处理，本页使用当前已完成的实际装箱。
4. 需要调整时，在未被草稿占用前使用“改装箱”“换店铺/换链接”“修改报关”，填写原因。对应权限独立。换身份会生成新PK，原PK及历史保留；不写领星。
5. 勾选PK选择全部可用装箱，或展开后仅选主箱/尾箱。只能同账号、同店铺、同测试标记；同一装箱行不能重复使用。
6. 点击“生成货件草稿”，填写美国退货地址，核对箱数/件数/草稿分组。ITS只保存选择，外部资格下一阶段核验。
7. 点击“保存为待审批草稿”。成功显示真实草稿号；页面刷新占用。此时尚未获得Walmart计划号/货件号，也没有箱唛。

有有效草稿占用后，该PK禁止改箱/换身份/改报关；尾箱尚未占用时仍可单独提交。当前阶段不开放撤回或释放，不能通过删除记录解除。

请求失败保留表单；同请求重试保持幂等键。版本/占用冲突时关闭弹窗、刷新并核对后重新选择，不连续盲目提交。服务失败显示错误，不等于当前没有业务数据。

测试记录标“测试”，不计正式供货/在途/异常。当前本地is_test环境保护和业务测试标记分别保存，不自行改历史数据。

审批、部署AI写Walmart、箱唛以及外部取消/改数量属于下一阶段。本页无外部API调用。
