# 关键词投放 · 规则配置（模拟验收版）

从「AI 中心 → 关键词投放」右上角进入；该页面不出现在左侧导航。

- 点击「创建规则草稿」后，所有业务配置可编辑。规则包括评分、分级 P0/P1/P2、各等级与 Exact/Broad 名额、参考 ASIN 数量、风险词、Bid、预算、Campaign 模板、Listing 和导出字段。
- 点击「比较修改」查看完整规则快照的差异；点击「模拟回测」仅根据目前可用的演示关键词计算对比，不作真实转化预测。
- 校验通过后可以「发布模拟版本」；版本只保存在当前浏览器会话。历史分析分数、导入原始指标不自动覆盖。
- 从历史版本复制到草稿是可逆操作，不等于数据库回滚。

**安全边界：** 任何看起来像模拟发布的操作都不会写入服务器、API、平台广告或真实利润计算。Excel 字段规则修改并不保证兼容 Walmart 官方上传模板。
