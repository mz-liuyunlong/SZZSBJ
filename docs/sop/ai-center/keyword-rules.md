# AI 中心 · 关键词规则

**状态：服务端规则草稿与审批工作流；未批准的 D01–D08 不视为正式规则。**

1. 选择账户范围，读取服务端规则集及版本。规则内容和审批状态以服务器返回为准，刷新页面会重新读取。
2. 具有相应权限的创建者可建立新草稿，选择版本后查看冻结配置、哈希和八项决策状态。修改方案需提交具体内容与证据编号；D04 必须选择缺失数据策略。
3. 审批人必须使用独立身份；创建者不能自审。可通过或驳回每项决策，事件会留痕。驳回后创建者可以重新提交。
4. 八项均通过、配置哈希未变且满足独立审批条件后，另一名有发布权限的人员才可发布。页面按钮状态不是最终授权，后端会再次验证权限、身份和版本。
5. 已发布版本的内容不可修改；退役不删除历史版本和旧分析。比较视图仅展示当前版本与草稿的配置差异。

**操作边界：** 真实批准人由服务端登录身份确定，不能在请求中自称。页面不会通过任意字符串绕开审批。发布规则也不等于授权 Walmart 上传、创建广告或重算旧批次。只有本地安全写入明确开放时才可在非生产环境执行这些写操作。
