# AI 中心 · 关键词规则

**状态：关键词投放页内可持久保存的规则草稿。未批准的发布策略例外不视为正式规则。**

1. 打开“AI 中心 → 关键词投放”，点击页面内的“规则配置”；地址仍是 `/ai-center/keyword-launch`。
2. 选择有账户归属的 Listing，在页内创建草稿、调整参数、比较修改并预览当前导入关键词的分级影响；点击“保存草稿”后可刷新恢复。
3. “发布本地版本”当前显示发布门禁提示，不会发布服务端规则，也不会批准 D01–D08。
4. 历史版本可复制为新草稿并保存；既有分析结果不会因草稿调整而自动重算。

**操作边界：** 草稿编辑配置已保存到后端，页面预览仍为本地预览；正式评分只采用已发布的后端规则。当前发布策略仍有独立发布人和 D01–D08 门禁，待项目审批例外正式落地。草稿保存不等于 Walmart 上传、创建广告或重算旧批次。
