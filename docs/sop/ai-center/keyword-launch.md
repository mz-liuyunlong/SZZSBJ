# AI 中心 · 关键词投放

**状态：本地 V1.1 复核工作流；未获业务规则、平台模板及上线审批，不可用于正式投放。**

1. 在「商品与来源」选择商品及未归档 Listing，核对 Item ID 和账户范围。商品候选来自现有后端；最终身份仍由关键词后端核验。
2. 填入已保存、验证通过的页面来源快照 ID，逐字段确认商品事实和风险边界。可追加有证据编号的复核短语；自有/竞品品牌须另由规则中的批准品牌清单证明。保存会生成新的不可变事实快照，旧分析不会改写。
3. 可关联已保存的 ASIN 来源快照。没有实际来源快照或授权时，界面不会伪造抓取成功。
4. 上传 `.xlsx`。后端保留原文件和所有工作表原始行；标准词去重不删除重复来源或观测值。上传前需要本地安全写入开关及私有存储配置。
5. 点击「检查分析条件」查看缺失证据和审批。满足来源条件后可创建**内部复核批次**，逐词查看主类型、页面承接、六维证据、拒绝原因。没有可靠数据的分量保持空值，不会自动变成可投放等级。
6. 选择历史批次可从后端重新读取结果；页面刷新后重新查询已保存的来源和历史。下载的是同一冻结批次派生的内部五表，不是 Walmart 官方上传模板。

**操作边界：** D01–D08 均须独立审批；没有已核验的官方模板和明确授权时，不生成或上传正式广告文件，不调用 Walmart Ads 或外部采集接口。页面上的「旧版本地草稿」只用于对照，不持久化、不可代表正式结果。任何真实业务写入都受服务端权限、账户范围及本地显式开关约束。
