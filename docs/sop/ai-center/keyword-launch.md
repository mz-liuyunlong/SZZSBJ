# AI 中心 · 关键词投放（模拟验收版）

**状态：`mock_only`，不是广告生产功能。**

1. 在 AI 中心打开「关键词投放」，先选择 SKU。模拟已有词库的 SKU 会提示进入「广告 → 词库」，不会要求重复上传。
2. 选择演示新品 SKU；粘贴多个 ASIN（每行一个，默认至少 3 个），再上传卖家精灵关键词拓展 XLSX（支持 CSV/TSV）。
3. 页面真实解析 Excel 的「关键词」、翻译、月搜索量、月购买量、PPC、关联 ASIN、`Unique Words` 和 `Asin` 工作表。**ASIN 表只有 ID，不等于已经抓取竞品文案**。
4. 确认后生成本地 mock 分级和 Exact/Broad 投放候选。结果可切换「投放决策」「市场与竞品数据」「投放方案」「Listing 文案」。
5. 英文关键词显示在上、中文翻译在下；可以编辑翻译。批量补翻译仅依赖有限的演示词典，未命中的保留「待翻译」。
6. 「下载 DEMO」只是本地资产报表，不是 Walmart 官方广告 Bulk Upload 文件。
7. 页面右上角的「规则配置」管理演示权重、阈值、名额、Bid、ASIN、Listing 和导出规则；发布只影响后续新的演示分析。

**安全边界：** 未连接 Walmart Ads、Amazon 竞品获取、LLM 或业务数据库；不得把 Amazon PPC / 市场购买率当成 Walmart 实际 CPC / CVR。所有数据留在浏览器当前页面会话，刷新后不保证保留。
