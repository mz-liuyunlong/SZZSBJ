# WFS 异常中心 SOP（M1）

## 入口

PMC → WFS → **异常中心** Tab。右上角 **?** 打开本说明。

## M1 能力

- 查看已持久化的异常**案件**（非旧页面 mock）
- 分配负责人、备注、待外部反馈、解决、关闭、重开（需对应动作权限）
- 货件看板抽屉可跳转关联案件

## M1 限制

- 不会自动根据领星数据新建案件；本地无数据时空列表正常
- 数量对账与申诉倒计时在领星/设置接入前显示「待核实」
- 不向 Walmart 自动提交申诉

1. 执行 Alembic 至 `20261029_0069_wfs_exception_center`
