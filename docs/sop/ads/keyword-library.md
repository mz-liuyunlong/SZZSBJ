# 广告 · 关键词词库

**状态：后端持久词库的本地 V1.1 验收；不表示广告已投放。**

1. 选择账户和商品，按关键词、状态筛选并翻页。默认页面从后端读取该商品的持久词库，不以浏览器内的模拟结果代替。
   点击“跨 SKU 关键词”后，由后端按账户隔离、搜索、来源和等级筛选及分页；关联 SKU 数量来自当前账户数据库。
2. 每个标准词只保留一条商品词库记录，但 Excel 原始行、来源事件和市场观测独立保存；列表显示来源种类与数量，不把重复数值取最大值冒充真实口径。
3. 可逐条或批量录入后台人工词，后端按账户、商品和请求键保证幂等；新词先进入复核状态。人工录入不等于自动广告搜索词或平台已授权报告。
4. 最新分析等级仅引用已保存批次。刷新页面后重新查询词库和分析，不改变原始来源、旧批次或人工词状态。

**操作边界：** 自动广告搜索词及授权报告在缺少可信来源契约时不能伪造为已导入。词库和内部五表都不是 Walmart 官方 Bulk Upload 文件；正式投放、上传与外部同步仍关闭。
