# 广告 · 词库（模拟验收版）

沿用系统原有「广告 → 词库」导航，按 SKU 查看关键词资产，或切换「跨 SKU 关键词」。

- 每个关键词可关联多个 SKU；独立保存各 SKU 的分级、分析版本和模拟投放状态。
- 英文原词蓝色在上、中文翻译灰色在下；无翻译显示「待翻译」。修改翻译后，在同一会话的两张页面中同步更新。
- 标签页包含「全部关键词」「待测试/复查」「计划与实际投放」「广告效果（演示）」「分析记录」。
- 「记录后台新增词」需录入 SKU、店铺、Campaign、匹配方式和 Bid。若无法归属，可放入待认领队列；这是人工记录，不是 Walmart API 同步数据。
- 「补充 Excel」真实解析卖家精灵文件，并新增未收录词，避免覆盖原有评估结果。
- 广告数据为合成 mock；无实际广告接口的情况下，「未同步」不等于「未投放」。CPC、CVR、ACOS 由本次模拟点击、花费、订单和销售额计算，不能作为实际业务依据。
- 「下载 DEMO 词库」并非广告可执行的上传文件。
