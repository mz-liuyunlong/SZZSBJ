# 国内仓打包单审批：本地验证操作说明

1. 正常登录本地系统，进入PMC→国内仓看板→打包单审批。本页仅处理惠州16168的采购入库候选；当前AD调拨和手工添加未开放。
2. 店铺、超时、到货未知、SKU/入库单/采购单、生成日期均请求后端筛选；生成日期是到仓日，PK尚未发号。到货已到/未到显示“—”代表缺标准收货事实，不是0。
3. 待补资料的行悬浮状态查看原因；无店铺、商品不符合条件、GTIN/MSKU缺失、可用量未知或分配完时不能通过。若资料发生变化，需刷新来源数据后重试。
4. 有动作权限时点击通过，填写正整数且不超过可用量；多ItemID必须明确填写数量。报关默认保持未知，也可明确选择报关/不报关。收货仓文本仅备注。确认后真实写入本地OPS/EVT并生成PK，全程不创建领星OWS。
5. 驳回必须填写原因，驳回后为终态。审批记录可查看已通过/驳回及对应来源版本和审计事件。M1不提供撤销、作废、再次审批或手工修改入口。
6. 网络失败保留同一次请求幂等键，成功前不假设已批准；409时刷新查看是否已有审批记录及剩余量。服务端拒绝重复、超量和跨账号操作。
7. 缺动作权限时按钮禁用。权限管理员在已有角色管理中配置packing-approve/packing-reject；系统仅新增定义，没有自动授权。超级管理员正常使用已有权限模型。

所有当前记录为本地验证单，不代表生产已审批或已在领星建单；历史覆盖、OWS联动和完整收货标准化需后续切片。不要把本地验证表复制到生产。数据库查询见docs/delivery/local-packing-approval-verification.sql。
