# SKU推进备注及批量采购（本地候选）

点击备注旁编辑按钮，原备注、原因和状态回填。填写备注，暂停/终止时选择原因。暂停后可选恢复推进。已完成/终止暂不允许重新开启，但可补充备注。保存失败或版本冲突先刷新，不能覆盖他人更新。推进状态列仍仅展示。

在当前页勾选符合条件的SKU，点击批量采购，逐个选店铺，每SKU固定20件。确认后逐条提交原采购接口。已提交显示单号；失败/待确认核实领星与本系统记录，不重发。关闭页面会停止继续排队，已经发出的请求仍须核对。无采购权限或真实采购开关未启用时不可提交。真实采购启用前必须核对权限、旧审批互斥、真实数据库及回执。国内发货和独立站未确认数据源，不补造。
