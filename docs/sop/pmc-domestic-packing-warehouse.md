# 打包单（仓库）本地操作

1. 独立用户登录。仓库具备查看、保存装箱、改装箱及完成权限；中台另授未装处置、延迟备注、登记IB、同步权限。本轮没有自动改变用户/角色授权。
2. 核对PK/SKU/审批Q，填写箱行，暂存不是完成。到仓日采用入库日，实际收货无证据显示待核实。
3. 等量直接完成；少装选择原因，其他须说明。包装资料缺失须补填单品尺寸与毛重。本PK只完成一次。
4. 多装余量够时勾选确认占用同SKU其他在仓库存；预算已扣原Q及其他有效分配。详情可核对额外来源IB及数量。
5. 余量不足须填超发原因，提交后仅记录阻塞及本地待通知，橙标显示缺口；不是完成。仓库可改箱，回到允许范围自动解除，之后人工再次完成。
6. 中台在外部手工补入库后点已补入库单登记IB，再点同步。当前默认真实领星未配置，页面会明确提示；本轮仅在隔离进程验证模拟同步。匹配后仍要仓库重新确认完成，不能把登记当作入库成功。
7. 未装待中台处理：下次再发释放未装占用，后续人工审批新PK；作废未装须说明且保留排除占用，不在领星伪造库存核销。
8. 完成后不能普通暂存或再次完成，改动走改装箱并写原因；保留首次完成时间。若改装箱缺口不足，保存提议、原实装不变；修正或补齐后再次提交。未装已回池/作废的单据当前阻止改装箱，防止反向占用已再分配库存。
9. 详情查看操作人、前后数量、额外来源与同步结果。冲突后刷新核对；网络重试复用同幂等键。

批次看板异常卡片统计惠州仓全部授权可见PK，与入库表格筛选数量分开。机器人任务只存本地，无实际发送。货件草稿和领星箱规使用实际箱行是后续对接约定，本轮未创建货件、未写领星、未动生产。
