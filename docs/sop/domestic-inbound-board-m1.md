# 国内仓入库批次查询说明

本期提供独立入库单API，原页面仍调用收货批次接口，尚未切换。

1. 先在数据采集环境核对惠州仓库和来源账号，采集CSV检查记录、余额与完整性。
2. 未经明确数据库发布，API不会读取CSV或领星后台自动填数。
3. 发布后按入库单、SKU、仓库、店铺或业务日期查询。入库单可能拆为多个店铺行，不能将父级入库数量重复累计。
4. 空列表时先看meta.data_status：not_published表示尚无当前发布；ready表示已发布后当前筛选确实无记录。
5. 余额为零不代表已发货；未知余额不等于零。源时区未核实时在仓天数不展示。
6. 查看trace可核对入库事件和对应批次。发货完成率、打包状态和系统PK暂未接入，不从数量相等猜关联。

接口路径、字段、筛选和错误码见 `docs/api/pmc-domestic-inbound-board-api.md`。页面后续切换时再把本说明挂接页面帮助入口，不覆盖当前收货页面帮助。

## 2026-10-20 店铺与负责人

店铺和负责人下拉从当前已发布入库数据的全部可见范围加载，支持名称搜索、多选后确认；提交稳定店铺ID和当前产品负责人UID，应用后回到第一页，列表与统计一起更新。负责人代表当前产品资料归属，不是收货时归属。没有资料或身份歧义的SKU不会猜负责人。加载失败点击“重试筛选选项”，重置清除全部条件。

业务状态六项为在库、待打包（领星打包单已建）、已打包待发、超时未发、已发出、非发货出库。当前仅声明能力并显示不可选，等待打包与出库数据方案实施；零余额不等于已发出，7天库龄不直接等于超时未发。
