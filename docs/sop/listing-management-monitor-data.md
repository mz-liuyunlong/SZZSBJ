# Listing 管理：监控数据使用说明

## 页面显示规则

Listing 管理仍使用现有页面和权限。标题、划线价、在售价、类目、购物车状态、Walmart
卖家、是否被跟卖、评分、评论数、品牌存在有效监控值时优先显示监控值；最新监控值为空
时显示现有 Listing 数据。

页面可查看监控来源、上次成功观察时间、数据年龄、状态、错误码和安全图片列表。
这些信息来自当前监控投影；失败的观察只保存在标准化历史中，不会覆盖最后一次成功的
监控业务值。因此页面的监控状态和错误码不代表“最近一次尝试”的结果。
RAW 事件标识和来源原始类目不在运营页面展示，RAW 内容仍受审计权限保护。

## 安全与排错

- 页面/API 不直接读取 RAW。图片只展示 HTTPS 地址；无有效监控图片时回退到现有商品图片。
- 监控接入不修改 Listing 稳定业务键，也不写现有 Listing MART。
- 跟卖必须来自监控端明确结论；仅出现其他卖家不会自动判定跟卖。
- 历史 RAW 回放默认 dry-run；生产 commit 需要单独审批和确认参数。
- 类目变更与恢复通知由监控端产生，新系统保留观察历史用于核对。

如果页面值与监控不一致，先核对最近监控是否成功以及对应字段是否为空，再由有权限的
人员检查标准化观察和 RAW 留痕；不要直接修改 RAW。
