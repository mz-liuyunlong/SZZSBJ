# 新品管理 Listing 首批采购验收 SOP（0103）

1. 同 SKU/店铺下两个 Item ID 各显示独立采购三列及复选框。Item ID/MSKU 左边缘对齐，复制与跳转功能不变。SKU 级基础信息、备注和推进仍合并。
2. 当前行提交采购，弹窗店铺、Item ID、MSKU 和20件数量全部固定。批量选择两个 Listing，合计40件；每行独立回执；不自动重试。任何不可采购行不得勾选或提交。
3. 采购计划成功只更新对应 Listing；PMC 数据按已核实计划及 Item ID 跟踪。国内发货仍待确认。历史归属不明确时该 SKU/店铺待确认，禁止盲目补发采购计划。
4. 在隔离测试中验证同店不同 Item ID、重复项、未知结果、历史 NULL、取消、固定数量及原等级/权限限制。验证列表/统计/筛选仍按原请求机制及 SKU 去重。0103 迁移须独立审核；源码安装不运行迁移。禁止用真实采购作为自动测试。
