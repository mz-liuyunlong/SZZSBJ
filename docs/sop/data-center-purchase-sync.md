# 任务中心：采购看板同步

路径：数据中心 → 任务中心 → 采购看板同步。每个已注册数据源账号一行。

1. 点击“配置”，确认账号，设置自动同步及“每3小时”，保存并确认。实际开启需要管理员已完成来源授权和任务初始化。
2. “立即同步”执行采购计划、采购单、收货单、清洗、看板刷新整条流程。无需填写日期；首次自动补齐2026-08-01以来数据，以后按更新时间增量同步。
3. 任务运行由后台执行，不需要一直打开浏览器。关闭自动同步只停止后续定时触发，已在运行的任务不会被强制终止，仍可手动执行。
4. 日志中的“完整流程”成功才代表整条流程完成；三个来源单独成功不等于看板已刷新。“详情 → 执行批次”可查看每个阶段及失败位置。
5. 失败时先检查日志，再从父任务重试；重试使用原日期范围，已有数据去重处理。不要分别开启三个来源任务，不要把“已排队”当成完成。
6. 原采购服务、数据与历史日志保留，页面只合并操作入口；产品、Listing、销售、广告、国内仓等其他任务独立运行。

三小时为固定UTC整点计划，台北时间02:00、05:00、08:00、11:00、14:00、17:00、20:00、23:00。手动触发不会重设定时计划。

缺少任务时由管理员检查注册、账号范围和权限；来源禁用时由管理员核查集成授权。本文不授予生产运行权限。后端使用 integrations:read/update/execute 和数据源账号范围进行校验。
