# Listing 管理：查看计算记录

在 Listing 管理打开“计算记录与 C/D 跟进”，可查看自己有权限的诊断批次。点击批次的“逐商品”，查看每个 Listing 的当前值、候选值和缺失证据代码。表格按服务端分页；切换账号后只显示该账号可见的快照。

“候选”不是正式生效。若有广告报表、每日销售、WFS 库存或规则版本缺失，查看证据代码并等待对应同步完成；不要人工把缺失日期当作零销量或零库存。没有历史完成标记的旧日期不会自动补成“已完整”。

C/D 跟进仅来自正式发布的快照。正式评级和自动调度当前受独立生产授权控制，诊断抽屉本身不触发同步或写回。

拥有“计算全部 Listing”权限且后台开关已启用时，可以在计算记录抽屉点击该按钮并确认。
系统只提交一次后台诊断，逐条结果仍是候选，不会因为手动计算自动发布。
请求状态和安全错误码可在同一位置查看；后台会重新核对是否拥有全部账号的数据范围。

拥有“撤回评级发布”权限且发布开关已启用时，可在逐商品结果中对最新发布点击“撤回”，
填写原因并确认。若 Listing 已有后续发布或人工调整，系统拒绝撤回，需先核查当前状态。
撤回保留原快照与操作人、时间、原因，并取消尚未完成的该次 C/D 跟进。

C/D 提醒按已保存的中国时间规则生成，只有正式发布且未完成的跟进才会参与；
通知投递还受独立业务通知开关控制。未配置或未启用时不会对外发送。

## 人工调整生命周期

当正式写入功能经单独授权启用后，有申请权限的人员可在 Listing 的「计算依据」窗口选择新的生命周期、填写原因并完成二次确认。另一名有审批权限的人员在同处查看待审记录、填写审批说明并确认。申请人不能批准自己的申请。若期间 Listing 的原阶段、账号或归档状态变化，旧申请会被拒绝，需核查后重新申请。

人工批准的阶段优先于自动计算。调整记录持续保留；需要改回时，提交新的反向调整申请并由另一人审批，不删除原记录。没有权限或生产开关未启用时，页面不显示写入入口。不要把旧历史阶段无记录的日期倒推成已审批。
