# docs 目录说明

本目录保存项目级开发规范、业务规则、技术规则、架构说明、数据源说明、外部平台只读参考资料和 AI 开发交接文档。

AI 开发任何功能前，必须按任务类型读取相关文档，不允许只凭聊天上下文写代码。

---

## 目录入口

### 外部接口参考资料

- `docs/integrations/`：外部平台的离线只读参考资料。文档存在不代表已批准接入；任何真实接口接入必须另行完成 PRP、官方文档复核、安全设计和后端任务。

### 数据源候选映射

- `docs/data-sources/`：旧库、外部 API、新系统页面之间的数据源候选映射。该目录内容默认是草稿和分析依据，不是最终架构批准。

---

## 目录建议

```text
docs/
├── api-contracts/        # 实际 API 契约
├── page-specs/           # 实际页面需求
├── old-system-analysis/  # old-system 只读分析输出
├── adr/                  # 架构决策记录
├── handoffs/             # AI 开发交接文档
├── integrations/         # 外部平台离线只读参考资料
└── data-sources/         # 数据源候选映射草稿
```
