# AI Token 效率规则

## 文件用途

本文件用于减少 AI 在大项目开发中的上下文浪费。

## 规则

AI 应该：

1. 先定位相关文件，再修改。
2. 优先读取组件清单、模块清单、API 契约。
3. 不要每次重新解释整个项目。
4. 不要重复粘贴大段已有代码。
5. 只展示关键 diff 摘要和风险点。
6. 大任务必须写 handoff 文档。
7. 页面开发前先复用已有组件。
8. 后端开发前先复用已有模块。
9. 不要输出无关文件全文。
10. 不要在同一会话无限堆上下文。

## 交接

上下文变长时写入：

```text
docs/handoffs/YYYYMMDD-task-name.md
```
