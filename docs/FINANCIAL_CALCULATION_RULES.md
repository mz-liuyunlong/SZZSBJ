# 财务计算规则

## 文件用途

本文件用于约束销售额、回款、广告花费、退款、退货运费、供货价、利润、毛利率、退款率等财务指标的计算方式。

## 核心原则

1. AI 不允许自行发明财务公式。
2. 所有金额字段必须带币种。
3. 页面展示金额必须说明口径。
4. 利润公式必须写清楚。
5. 退款是否计入必须写清楚。
6. 广告费是否分摊必须写清楚。
7. 退货运费是否计入必须写清楚。
8. 汇率来源必须明确。
9. 财务计算必须有测试样例。

## 常见指标待确认项

| 指标 | 必须确认 |
|---|---|
| 销售额 | 是否含税、是否含退款 |
| 回款 | 是否按平台结算、是否扣除平台费 |
| 利润 | 收入、成本、物流、广告、退款、平台费口径 |
| 退款率 | 分母是订单数、销售额还是件数 |
| 广告占比 | 分母是销售额还是回款 |
| 供货价 | 活动供货价优先还是商品供货价优先 |

## 禁止

AI 不允许在不确认口径的情况下写财务公式进入生产逻辑。
