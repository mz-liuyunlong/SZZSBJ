# 禁止或暂缓接入清单

本文件用于防止 Codex 或工程师看到 OpenAPI 文档后直接接入不适合当前项目的接口。

## 总原则

以下接口默认不得进入第一期：

- `normalized/deleted_interfaces.csv` 内所有接口。
- 非 Walmart 平台专属接口：Amazon / 亚马逊 / FBA / FBM / ASIN / FNSKU / VC / MWS / TEMU / TikTok / Shopify / Shein / eBay / AliExpress / Alibaba / Lazada / Shopee / Coupang / Wayfair / Kaufland / Mercado / OTTO / Ozon / Qoo10 / Rakuten / Cdiscount / Line 等。
- 顶层广告模块中已删除的接口。
- 写入类、有副作用或会改变平台/ERP 状态的接口。
- 上传、创建、删除、批量修改、启用/禁用、价格修改、库存修改、采购修改、Listing 变更等接口。
- 无法确认 Walmart 适用性的多平台接口。
- 无法确认账号权限或返回字段的接口。

## 允许重新评估的例外流程

如果确实需要重新评估被删除或暂缓接口，必须满足：

1. 负责人明确批准。
2. 架构师提供 PRP。
3. 说明为什么该接口适用于 Walmart。
4. 说明是否只读、是否有副作用。
5. 在沙箱或只读方式完成真实验证。
6. 更新 `api-verification-status.csv`。
7. 不得在同一 PR 中同时做大范围业务接入。

## 一期安全策略

第一期只考虑：

- 查询型接口。
- 可以作为旧库数据来源替代候选的接口。
- 能明确映射到新系统页面的数据。
- 低频、低风险、可回滚的接口。

暂不考虑：

- 写平台状态。
- 写领星 ERP 状态。
- 创建或修改 Listing。
- 修改价格、库存、采购、仓库、发货、退款。
- 直接影响订单、结算、广告投放的接口。
