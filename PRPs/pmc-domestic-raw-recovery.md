## 1. 目标与范围

从已保留的历史 RAW 验证并恢复国内仓来源投影，再使用现有发布器重建历史批次看板。不得重新请求领星，不改列表取数口径，不把历史快照标成当前库存。

先批准本地脚本开发和隔离验证；生产读取、恢复及发布分别明确执行环境与权限，不包含在开发批准中。

## 2. 已有证据

证据来自用户在数据库工具执行只读 SQL 后提供的截图，不等于本助手直接连接生产所得结果：

## 3. 数据源与业务契约

复用已保留的来源证据，不新增业务 API，不改变字段来源、数量公式或权威归属。本 PRP 属于恢复工具方案，不是新增接口 PRP；适用前须复核原始入库看板 PRP、数据库分层和字段标准化规范。若演练要求改变语义或来源，停止并另走数据源决策门禁。

链路：成功 run + 请求引用 + RAW → 现有国内仓 parser → 原有 ODS 与血缘 → 现有 inbound builder / publisher → 版本化 MART → 原 GET。

不创建数据库表、不修改 Alembic 版本、不修改 .env、不更改账号或角色权限、不修改原成功任务状态和累计数量。原 RAW、引用、任务及历史证据保持不变。

## 5. 执行阶段

### A 本地工具与合成测试

核实真实 parser、ODS 约束、RAW 请求参数、血缘模型和现有业务外键。默认 dry-run，不使用原同步 handler 的 execute 直接重放，因为该入口会修改任务状态、累计数量，并可能发起网络请求。

校验明确的 run 白名单、provider、interface、账号、仓库、成功状态、成功响应、正文、请求分页、窗口、包含零库存参数及重复身份。验证源数据 checksum 时遵循当前已有序列化规则；不擅自假定散列算法语义。

恢复保留原 run_id、raw_request_ref_id、行序号与来源观察时间；新建 ODS 行身份须能与血缘对应，不篡改原任务计数。现有残留血缘如指向不存在的旧 ODS，必须保留并明确恢复血缘策略，不能静默删除。

### B 历史数据隔离演练

实际 RAW 不自动拷贝到本地。优先在服务器受控隔离环境演练；若需导出，由负责人另行批准数据范围、目的地、存储和清理方式。

使用原 run 的固定证据集，禁止外部网络调用。核对历史 W1 1528、W3 1264；若不一致停止并报告，不能补造数据或强行凑数。通过现有 builder 验证行级内容、数量去重、日期与报关依赖；历史看板 1441 行作为对账参考，不作为可强制实现的结果。

来源时区按历史确认 Asia/Shanghai 复核；UTC 瞬时与业务日期不可混淆。现有采购数据对报关投影的影响必须披露，不能宣称一定重现旧版全部 payload。

### C 生产只读预检

需有受控执行通道和明确读取授权。核对线上服务实际数据库/schema、目标指纹、运行中任务、两次 run、11 条 RAW 引用、目标表计数以及是否有其他业务引用。默认只读、超时退出，不打印凭据、RAW 正文或完整连接信息。

### D 生产恢复与发布

仅在负责人审查 A/B/C 结果并单独批准后执行。先做目标相关证据备份并验证可恢复性；定义账号/仓库互斥、锁超时、语句超时和预期计数门禁。

恢复 ODS 与恢复血缘必须同事务；重复执行时验证已存在记录与来源一致，相同则跳过，冲突则失败，不静默覆盖。生产实现前须明确与现有同步和发布共享的互斥策略，不能只依靠运行前查询防并发。

ODS 提交后独立调用现有发布器，发布失败保留已验证 ODS、RAW 和审计，以便重试；不得承诺 ODS 恢复与已有 publisher 的内部 commit 是同一个事务。

完成后核对唯一 current published、MART 行数、列表/统计版本一致、真实登录页面和来源时间。发布恢复不包含自动采集调度。

## 6. 测试与验收

- 合成测试覆盖正文缺失、失败响应、分页缺口、错误账号/仓库/run、重复冲突、已有部分 ODS、残留血缘、异常回滚和重复执行。
- 真实 PostgreSQL 验证仅在明确隔离环境，禁止测试写生产。
- 默认模式零写入；不调用领星或 Walmart；不改任务状态、原计数或业务权限。
- 真实历史演练结果与合成测试分开报告；RAW 未获读取/导出授权时不能声称完成历史演练。
- 后端定向 pytest、Ruff；无前端代码变更，无需新增页面 E2E。正式恢复后做只读页面验收。

## 7. 回滚与停止条件

事务内错误直接回滚。ODS 成功提交、发布失败时允许保留 ODS，不删除证据。发布成功后的撤回需评估已有业务外键和当前版本兼容性；首次发布无旧版本可回退，禁止直接清空 MART。恢复脚本不得实现通用生产删除入口。

环境身份不明、RAW 不完整、数据冲突、存在未识别写入方、无法保证互斥、备份不可恢复或业务引用不明，均停止生产写入，提交具体问题。
