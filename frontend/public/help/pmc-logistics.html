# 物流使用说明（按 8088 物流 Demo 上线）

1. 一张领星 SP 发货单 = 一行。只看 2026-07-01 起创建的发货单，PMC-TEST- 测试货件及其发货单不计入。 2. 数据来自本系统已入库的数据：领星发货单 / WFS 货件（当前 WFS 看板发布版本）、领星物流渠道、众壹运单与轨迹、Walmart 货件与 Receipt 流水。页面只读，不调用领星、物流商或 Walmart 接口，也不写回领星。 3. 所有天数按“数据日”计算（同 8088：数据日 = 当次拉数日期），页面顶部显示数据日。 4. 当前阶段：待发货 → 已发货 → 已开船 → 已到港 → 派送中（靠港满 4 天）→ 物流签收 → Walmart 收货中 → Walmart 完成；已作废单独列出。 5. 到仓日期：有实际取实际（众壹“签收完成”与 Walmart 签收取较早）；没有实际按 众壹预约派送 → 实际到港+周期 → 实际开船+航程+周期 → 预计到港+周期 → 领星预计到货 → 发货日+地区兜底（美西 50 / 美中 60 / 美东 80 天）。 6. 可售日：Walmart 首次 Receipt（上架 ≥ 1 件即可售）；还没上架 = 到仓日 + 10 天缓冲。 7. 合同时效从提货次日起算，提前 3 天提醒；超时效按 0.5 元/KG/天 × 计费重（众壹 totalWeightKg，无则领星毛重）算可索赔金额。合同天数目前是 8088 的示例值，中台维护真实时效后再改。 8. 统计卡可点击筛选；点任意一行打开发货单详情：时间线、系统内物流时间对账、Walmart 回读、众壹轨迹、货件 × 产品、异常。所有列表都在服务端筛选和分页。

## 物流下的 4 个页面

1. 物流总览：一张 SP 发货单一行（上面 1–8 条）。 2. 到货预测：已发货、货件没关闭的“店铺 × MSKU”，按预计可售日分成 已过 / 15 天内 / 15–30 / 30–60 / 60 天以上；该货件该 GTIN 已有 ≥ 1 件上架的进“已到·收货中”（看 发货 / 签收 / 上架）。签收 = Walmart 货件明细 receivedQty，没有则用领星 received_num；上架 = Walmart Receipt 合计。每行带关联物流：发货单号 / 货件单号 / 运单号，搜索框可选按这三种单号分别搜。点一行看 货件 × SKU 明细（每行的发货单号、货件单号、运单号和物流商）。 3. 异常与提醒：一条异常一行，按严重度、发现日期排序；可按类型、严重度、店铺、物流商筛选。阈值、渠道分段时效、合同时效在「PMC 设置 › 时效与阈值设置」查看。 4. 货代看板（原“众壹接口面板”）：一张货代运单一行，含物流商（众壹是其中一家，目前只有众壹有已校验的运单文件，其他物流商在筛选里显示 0 张）、状态、计费重、最新轨迹、停更天数（未签收且最后轨迹 ≥ 7 天标红）；可按物流商筛选，搜索可选按运单号 / 客户单号（货件单号）/ 发货单号分别搜；下方列出领星有运单号但众壹文件里查不到的、以及众壹发货单没填运单号的。

## 当前实施边界

异常处理状态 / 负责人 / 通知渠道还没有上线；阈值本期为只读的 8088 默认值，修改入口待定。货代看板不显示 8088 的拉数调用统计和接口清单（新系统只读已校验文件，不调众壹接口）。
