# 物流看板使用说明（按 8088 物流 Demo 上线）

1. 一张领星 SP 发货单 = 一行。只看 2026-07-01 起创建的发货单，PMC-TEST- 测试货件及其发货单不计入。 2. 数据来自本系统已入库的数据：领星发货单 / WFS 货件（当前 WFS 看板发布版本）、领星物流渠道、众壹运单与轨迹、Walmart 货件与 Receipt 流水。页面只读，不调用领星、物流商或 Walmart 接口，也不写回领星。 3. 所有天数按“数据日”计算（同 8088：数据日 = 当次拉数日期），页面顶部显示数据日。 4. 当前阶段：待发货 → 已发货 → 已开船 → 已到港 → 派送中（靠港满 4 天）→ 物流签收 → Walmart 收货中 → Walmart 完成；已作废单独列出。 5. 到仓日期：有实际取实际（众壹“签收完成”与 Walmart 签收取较早）；没有实际按 众壹预约派送 → 实际到港+周期 → 实际开船+航程+周期 → 预计到港+周期 → 领星预计到货 → 发货日+地区兜底（美西 50 / 美中 60 / 美东 80 天）。 6. 可售日：Walmart 首次 Receipt（上架 ≥ 1 件即可售）；还没上架 = 到仓日 + 10 天缓冲。 7. 合同时效从提货次日起算，提前 3 天提醒；超时效按 0.5 元/KG/天 × 计费重（众壹 totalWeightKg，无则领星毛重）算可索赔金额。合同天数目前是 8088 的示例值，中台维护真实时效后再改。 8. 统计卡可点击筛选；切到“异常与提醒”看每条异常的类型、严重度、说明。点任意一行打开发货单详情：时间线、系统内物流时间对账、Walmart 回读、众壹轨迹、货件 × 产品、异常。

## 当前实施边界

8088 的“到货预测”“众壹接口面板”“时效与阈值设置”页签、异常处理状态 / 负责人 / 通知渠道还没有上线；阈值在本期为只读的 8088 默认值。
