PMC 总看板使用说明

总看板按 ItemID（多店铺合并）汇总采购、国内仓、在途、WFS 可售和销量，提示断货、过剩、供应链和执行异常。本页只读，业务操作回到各模块。本机 5173 过渡阶段读取一份 8088 数据日快照（每周刷新），页面顶部写明数据日；快照不存在时页面提示「数据未就绪」，不显示示例数据。

页面

  1. ItemID 主表：上方是筛选区，下面是 12 张统计卡（ItemID 总数、已断货、断货风险、供应链异常等），点一张卡只看这一类，再点一下取消；点「ItemID 总数」看全部。问题类型下拉里的数字是当前店铺、负责人、关键字条件下该类 ItemID 的个数。
  2. 仓库分布：国内仓、海外仓有库存的仓库，含可用、锁定、在仓天数分布。
  3. 规则设置：总看板使用的判断参数，一期只读，修改走规则版本。

操作

  1. 输入 ItemID、SKU、MSKU、品名或草稿号后回车搜索；可按店铺、负责人、问题类型筛选；「只看有问题的」默认打开；点「重置」清空全部条件和排序。右侧齿轮按钮可选择显示哪些列、调整顺序，列宽可拖动，设置只保存在本浏览器。
  2. 日销、WFS 可售、全链路供应、有库存天数、断货天数、预计断货天数、覆盖天数可点表头排序；不排序时按问题优先级排列。翻页和每页条数（50 / 100 / 200 / 500 / 1000）由服务端处理。
  3. 点一行打开该 ItemID 的详情：店铺分布、断货时间线、供应链批次、国内仓批次、异常提示和补货计算。
  4. 「下载 Excel」可下载全部或当前筛选的 ItemID；右上「口径说明」查看数据来源、未归属数量和海外仓说明。

边界

主表各段为自动补货互斥口径（可相加，不含海外仓）。Walmart 数据列、归档、草稿审批状态、运营日志本期未接入。本页不调用领星，也不写入 Walmart。
