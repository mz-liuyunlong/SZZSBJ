# 月报与月度规划系统 开发方案（定稿版，2026-07-14 深夜）

需求方已确认全部口径（对话记录 2026-07-14），本文档为开发基准。核心原则：
**月报按 ABCD 利润等级看经营结构、生命周期辅助判断阶段；问题产品全量列出；
月度规划结构化录入、机器自动对账考核；公司与每位负责人分别成报。**

## 一、定稿口径汇总（不再开放讨论）

| 项 | 定稿 |
|---|---|
| 利润等级 | 直接读 dim_product_business_state.profit_level（A/B/C/D/未评级），不重算 |
| 生命周期 | 实际六档：新品期/测品期/测品结束/上升期/稳定期/清货期；人工值优先系统兜底 |
| 新品定义 | 生命周期=新品期 |
| 等级环比 | 不做（快照仅保留9天）；只对比销售/利润（RAW 有历史） |
| 库存金额 | 库存数量 ×（采购成本+头程 first_mile_shipping_cost）÷ 6.6 折美元 |
| 缺成本 | 按 0 计入并分三级披露（完全无配置/缺采购/缺头程）；进问题清单要求补成本 |
| 问题产品条件 | 月毛利率<10% ∪ 批C规则信号命中 ∪ 月销量<30单 ∪ 周转>90天 ∪ 新品上架7天未出单 ∪ 缺成本 ∪ 缺负责人（全量列出，不截断） |
| 广告占比 | 月度广告费 ÷ 月度销售额（区别于ACOS） |
| 建议方向 | 复用规则信号 suggested_action，不另写阈值 |
| 历史SKU | 无WFS库存 且（创建<2026-04-01缺成本 或 0401以来零销量）→ 审核清单后批量置 inactive（清单已导出：A表0行/B表496行待审） |

## 二、月度规划（独立表 B 案，需求方定稿）

### 表：biz_monthly_plan（业务层人工数据，AI 只读）
关键列：plan_month(2026-08) / platform / store_id / item_id / msku / owner /
issue_text(预填月报问题) / indicator1_type(枚举) / indicator1_target(数值) /
indicator2_type / indicator2_target(可空，最多2个) / deadline(默认月末) /
normal_operation(0/1 正常运营表态) / note / created_by / updated_by / 时间戳。
唯一键：uk(plan_month, platform, store_id, item_id, msku)。
变体指标为"人工汇报"型：indicator_type=新增变体 时对账栏显示人工确认按钮，不自动判定。

### 指标枚举与量化目标（写死）
清货→清货≥件 ｜ 提高毛利率→月度综合毛利率≥% ｜ 提升销售额→月销售额≥$ ｜
新增变体→新增变体≥个（人工汇报确认） ｜ 调整广告→月度广告占比≤%

### 对账判定（下月4号月报自动，规则写死）
按整月数据判定（月度综合毛利率口径；月末最后7天作参考列不参与判定）：
✅达成（全部指标到位）/ ⚠️部分达成 / ❌未执行（有计划无记录且指标未动）/
🚫未填计划（进绩效名单）/ —观察中（正常运营表态）。

### 录入界面（运营日志 Tab 内新增"月度规划"区）
形态按已确认的 v2 设计稿：进度横幅（未填数+截止日）→ 待填清单（来自 AI 层问题
清单表）→ 结构化表单（产品自动带出/问题预填/指标最多2个可增删/量化目标随指标
切换/期限默认月末/正常运营勾选/选填备注）。日常记录录入完全不受影响。

## 三、AI 层问题清单表：ai_monthly_issue_item
月报生成时落库：report_id / plan_month / owner / store_id / item_id / msku /
issue_reasons(JSON数组) / suggested_action / 指标现值快照(JSON)。
三用：催办脚本算未填数、前端待填清单、下月对账回读。

## 六、月报HTML结构（公司/个人同构，个人只含本人产品）
1 目标完成（月/季进度+环比上月销售利润） 2 产品总盘 3 ABCD结构表
4 生命周期六档表 5 新品情况 6 全部问题产品（含建议方向+上月计划对账栏）
7 库存与资金占用（60/90天+积压=清货/长期无售/高库存低销量/持续亏损）
8 下月行动（放大/调整/清货 三分组自动候选）
生成器独立脚本 generate_monthly_report.py（复用周报取数模式与登记/推送链）。

## 七、6月报测试的如实标注（需求方已知悉）

仅按静态条件；6月目标为回填基线（×90%口径）。
