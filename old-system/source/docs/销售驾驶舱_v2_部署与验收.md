## 二、v1 日期规则（中国当前日期 = D）

昨天 = D-3 单日；近7天 = D-9 ~ D-3；近30天 = D-32 ~ D-3；
本月 = 本月1日 ~ D-3，空范围时兜底最新有数据日所在月（无 meta 时上月完整月）；
最新数据日（默认）= MAX(stat_date)；自定义不偏移。
日期计算用本地时区（非 toISOString UTC），避免早上 8 点前差一天。
筛选区已加说明："数据按美国业务日同步……快捷日期已自动避开最近未完成同步的日期"。

## 三、v2 口径要点

- 对比与排名变化直接复用 v1 buildDashboard 跑本期/上期两遍 → "本期负责人合计=公司本期指标"天然成立
- 上期默认 = 紧邻等长上一周期；"本月"由前端传 compare_from/to = 上月同期（同天数，封顶上月末）
- 按日趋势逐日计算毛利（同 v1 公式：扣采购/头程/WFS/佣金/广告，人民币成本÷汇率）
- 比例类指标（毛利率/ACOS/TACOS）变化按百分点显示（+1.9pct），不用金额百分比逻辑
- 颜色极性：销售额/毛利类涨=绿；ACOS/TACOS 涨=红；广告花费中性
- 页面模块顺序：筛选 → 卡片 → 环比对比 → 公司趋势 → 负责人排行 → 排名变化 → 下钻（含负责人趋势）→ 异常区
