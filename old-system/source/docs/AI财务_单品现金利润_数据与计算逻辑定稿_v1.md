## 一、模块结构与原则

**模块「AI财务系统」，三个tab（侧栏样式仿「广告系统」模块）：**

| tab | 内容 |
|---|---|
| **财务工具** | ①月度汇率人工录入（超管/财务，人工层表）；②CSV导入中心：对账单CSV（每两周）、仓储报告CSV（每月）、后续二期费用模板——全部导入入口统一在此 |
| **单品现金利润** | 现金视角：钱袋子进出多少、压了多少；采购下单当天全额记支出；固定开支**不摊** |
| **利润报表**（销售利润表） | 财务视角：卖出部分赚多少；已售数量×真实入库成本单价；固定开支按销售额占比分摊，出"分摊前/分摊后"两个利润 |

**账期口径（v1.5核心修正）**：核算周期=**沃尔玛账单周期**（每两周一期，起止日不固定、可延迟付款）；周期清单随对账单CSV导入自动登记，**核算时具体用哪个周期由人工（超管/财务）选择确认**；前端展示周期起止+回款日期+数据导入时间。

通用原则：真实账单优先，拿不到真实值显示"—"并注明；两表共用同一套数据管道；历史完整性从系统上线起算（成本历史缺失补批次成本接口`getBatchDetailList`）。

## 三、tab1 单品现金利润（逐列口径）

维度：店铺/ItemID/MSKU/SKU/品名；账期=结算月+「数据更新于yyyy-MM-dd HH:mm」。
**收入侧**：销售额、促销折扣(负)、退款售后(负)、税费净额、其他调整(按品)=丢失赔付/找回等#9赔付类。**收入合计=之和**。
**支出侧**：佣金、WFS配送费、**广告费(分类:SP手/SP自/SB/SV可下钻)**、仓储费、采购成本(现金口径#6)、头程、入库运输分摊(#8)、其他平台费(按品)=#9扣费类。**支出合计=之和**。
**计算列**：单品现金利润=收入合计−支出合计；投产比=收入合计÷支出合计；当前库存成本=真实入库成本单价×在库数量。
**店铺级行**：SEM、官方测评费、DiscountAdjustment无GTIN残差、货件匹配残差——单列，参与店铺合计不进单品行。固定开支**不进本表**。

## 四、tab2 销售利润表（财务报表，逐列口径）

维度与账期同tab1。每行两个利润数（需求方定）：

- **分摊前利润（毛利）** = 已售销售净额（销售额−促销−退款−税费净额）−已售数量×真实入库成本单价（采购+头程归集）−佣金−WFS配送费−广告费（全分类）−仓储费−入库运输分摊−其他平台费±按品赔付调整
- **分摊后利润** = 分摊前利润 −（固定开支分摊 + 销售相关费用【二期】）

固定开支分摊规则（需求方拍板）：分摊基数=**销售额占比**；公司级费用先按各店销售额摊到店、店铺级费用直接摊本店，再摊到品；公司开支全额归Walmart；**当期零销量品不参与分摊**（默认设计，防止费用摊给没卖货的品，最终确认见第十节）。分摊后利润列ⓘ注明分摊基数与当期固定费用总额。

## 五、人工复核机制（需求方定稿）

权限=**仅超管+财务**；粒度=**ItemID×账单周期**；复核对象=**销售利润表的产品成本+头程成本**（自算归集链路，最需人工把关）。复核只做"标记+备注"，永不改数；数据被同步刷新（金额变化）→复核状态自动打回"待复核"并提醒；固定费用录入与分摊结果纳入复核范围；未复核数据前端标注。

## 六、守恒哨兵报警体系（需求方定稿新增）

原则：**每类费用归属/分摊完成后，加总必须回得到账单原额；回不到=报警**（飞书通知超管+财务，并推进复核队列）。守恒等式清单：

1. 固定开支：Σ各品分摊额 = 当期录入的固定费用总额（公司级+店铺级）。
2. 广告：SP手+SP自+SB+SV各品合计+SEM店铺级+未归属残差 = 对账单"Walmart Product Advertising"+"SEM Marketing"扣款总额（发票级基准，如7月$14,430.60+$342.91）。
3. 仓储：Σ各SKU仓储费 = 仓储报告头部店铺总额（实测本就分毫不差，偏差即导入错误）。
4. 入库运输：Σ各品分摊 + 未匹配残差 = settlement报告InboundTransportationFee总额。
5. 收入：Σ单品行+店铺级行 = 结算接口该店该月合计（防归属漏行）。
   各等式偏差阈值（绝对值/百分比）在实施时定并写入帮助文档。

## 七、同步/导入管道（开工第1期范围）

①**对账单CSV导入（核算主线，财务工具）**：每两周人工从Seller Center下载对账单CSV→导入→RAW留痕→自动登记账单周期（起止/回款日）→交易级归属ItemID入FACT；重复导入幂等；配缺失兜底提醒。②领星结算月度同步（核查线）：每日重拉当月+前2月，（店铺+MSKU+结算月）幂等upsert，供双源核查。③仓储费CSV导入（财务工具）：按月导。④采购/头程现金线+成本归集：产出"真实入库成本单价"。⑤SB/SV广告同步：已定型（sba/video、day=14、paging布尔true），写入fact_ads_product_daily（R1）。⑥月度汇率录入（财务工具）+固定费用录入与分摊。⑦守恒哨兵（等式5升级：账单周期CSV合计↔领星月度重叠期匹配核查）。全部新增隔离开发，不碰现有表/脚本/cron。
