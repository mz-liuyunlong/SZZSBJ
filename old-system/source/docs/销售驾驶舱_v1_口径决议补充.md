# 销售驾驶舱 v1 口径决议补充（2026-07-03）

> 本文档为《产品负责人经营看板》方案的最终口径补充，与主方案冲突处以本文档为准。

## 一、已拍板口径

### 1. 退款
- 销售额 = `sales_amount`，**不扣退款**。
- `refund_amount` 单独作为展示字段（明细与负责人排行可加"退款额"列，第一版可只在明细展示）。

### 2. 毛利公式（含乘数）
```
毛利额 = 销售额
       − 采购成本(单价) × sales_qty
       − 头程成本(单价) × sales_qty
       − WFS配送费(单价) × sales_qty
       − 平台佣金
       − 广告花费
毛利率 = 毛利额 / 销售额（销售额为 0 显示 "-"）
```

### 3. 成本来源（不回退）
- 采购成本 / 头程成本：**只认** `dim_product_cost_config` 中 `source_system='lingxing_api'` 的记录，每个字段分别取该字段非空的最新 `effective_date` 记录（禁止单一 MAX(effective_date) 同时取三项）。
- 无 lingxing_api 记录 = 缺失，计入"缺采购成本 / 缺头程成本"异常，**不用飞书来源兜底**。
- WFS 配送费：来自 `dim_product_cost_config.delivery_fee`（feishu_item_owner 来源），与采购/头程分开取。
- 匹配键：优先 `store_id + item_id + msku`，未命中回退 `item_id + msku`，禁止只按 `item_id`。

### 4. 广告费不分摊
- 广告指标（ad_spend / total_sales / orders / ACOS）只在 **item_id 级**展示。
- 下钻明细中，同一 item_id 的广告指标单独一行（或 item 汇总行）展示，**msku 明细行不含广告费**。
- 负责人排行、公司卡片按 item_id 聚合广告费，不受影响。
- 明细行的毛利额相应不扣广告费；负责人/公司级毛利按公式扣广告费。页面备注该差异。

### 5. 负责人兜底
- 优先 `dim_product_owner`（`status='active'`，按 `platform + item_id` 归属）。
- 无 active 记录时，回退 `dim_product.owner` 兜底，页面标注来源（如"负责人(商品表)"）。
- 两处都无 → "未分配"，必须展示，不允许丢行。
- 公司卡片各指标合计必须 = 负责人排行合计（含未分配）。

## 二、补充条款（写进实现）

6. **库存快照口径**：库存取筛选范围内最新一天 `snapshot_date` 的快照值，禁止跨天求和。"WFS 库存商品数"= 该快照日 `wfs_available_stock > 0` 的商品数。
7. **库存天数窗口**：日均销量分母 = min(60, 实际有销售数据的天数)；日均销量为 0 显示 "-"。
8. **异常商品数去重**：卡片与负责人排行中，一个商品命中多个异常按商品去重计 1；异常区按类型各自计数。
9. **验收补充**：公司卡片的广告花费合计 = 负责人排行广告花费合计。有广告但无销售的 item_id（约 238 个的来源）必须进入负责人聚合，不允许丢失。
10. **佣金缺失标记**：`fact_profit_daily` 2026-06-24 前无数据且 `platform_fee` 样本多为 0。筛选范围内取不到佣金时按 0 计算并在页面标记"平台佣金缺失/未接入"，接口保留 `platform_fee` 字段。
11. **汇率/币种**：开发前确认 fact 表金额币种是否已统一 USD；若需汇率，读环境变量或配置表，**禁止硬编码**（现有 daily-metrics 写死汇率的问题不带入新接口）。
12. **默认日期**：取 `MAX(stat_date) FROM fact_sales_daily`，页面显示"数据日期：YYYY-MM-DD"。不默认今天/昨天（07-02/07-03 无数据）。
