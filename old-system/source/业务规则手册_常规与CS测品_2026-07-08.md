## 二、常规产品规则

### 2.1 利润等级 profit_level（近30天口径）

| 等级 | 条件 |
|---|---|
| A级【稳健款】 | 毛利率 >= 20% |
| B级【潜力稳健款】 | 15% <= 毛利率 < 20% |
| C级【优化整改款】 | 8% <= 毛利率 < 15% |
| D级【止损亏损款】 | 毛利率 < 8% |
| （空）数据不足 | 近30天销售额=0 或无利润数据 → 不判级，显示"-"，严禁默认D级 |

注：旧"S级【卓越款】(>25%)"已随旧评级体系退役。
利润等级只看毛利率，不混广告占比（广告问题独立成 ad_status）。

### 2.2 利润附加预警标签

| 标签 | 条件 | 语义 |
|---|---|---|
| 真实亏损 | 毛利率 < 0% | 只有负毛利才叫亏损 |
| 严重低毛利 | 0% <= 毛利率 < 5% | 重点止损对象，但不是亏损 |
| 低毛利风险 | 5% <= 毛利率 < 8% | 关注 |
| 利润数据不足 | 无30天利润数据 | 不参与清货期判断 |

### 2.3 生命周期（四阶段，判定优先级从上到下）

| 阶段 | 条件 |
|---|---|
| 清货期 | 库存周转天数 > 90 且 毛利率 < 8%（毛利率为空不判） |
| 新品期 | 有上架时间 且 距上架 <= 60 天 |
| 上升期 | 距上架 60~120 天 且 近7天销量比前7天增长 >= 50%（前7天=0且近7天>0 视为满足） |
| 稳定期 | 以上都不满足的兜底状态（不代表优秀，好坏由等级/库存/广告单独判断） |

- 缺上架时间：不判新品期/上升期，打"缺上架时间"标签
- 人工确认生命周期 > 系统推导（页面产品管理维护，人工值跨每日快照持久）

### 2.4 上架时间 launch_date

- 存量：2026-07-06 飞书人工回填 1,502 条，永不覆盖
- 增量（每日20:15自动，只补空、写一次不再改）：
  常规产品 = 首次 WFS 有库存日；CS测品 = 首次广告花费日
- 推不出的保持空，生命周期由人工处理

### 2.5 库存状态 inventory_status（单值优先级：缺货风险 > 积压严重 > 偏高 > 正常）

库存周转天数 = 总库存 / max(近7天日均销量, 1)；总库存 = 在库 + 在途
（已采购库存待PMC接入后并入）

| 状态 | 条件 |
|---|---|
| 缺货风险 | 有近7天销量 且（在库 <= 5 或 周转 <= 14 天） |
| 库存积压严重 | 周转 > 90 天 |
| 库存偏高 | 60 < 周转 <= 90 天 |
| 正常 | 周转 <= 60 天 |

组合预警标签：
- 周转>90 且 毛利率<8% → "低利润压库存"（+清货期）
- 周转>90 且 毛利率>=8% → "有利润但库存积压"（有利润也要清醒看库存）
- 近7天无销量 → "近7天无销量"标签
- 多状态同时命中：单值字段取优先级最高者，全部命中项写入 problem_tags
  （典型：在库<=5但在途大 → 状态=缺货风险，tags同时含缺货风险+积压严重）

### 2.6 广告状态 ad_status（30天口径；单值优先级从上到下）

| 状态 | 条件 |
|---|---|
| 广告浪费 | 30天广告费 > 0 且 广告销售额 = 0 |
| 广告无转化 | 30天广告点击 > 0 且 广告订单 = 0 |
| 广告占比偏高 | 30天广告占比 >= 18% |
| 广告无花费 | 近7天广告费 = 0 |
| 广告正常 | 其余 |

广告状态不影响利润等级；多命中全部进 problem_tags。
ACOS 表达规则：广告销售额=0 时 ACOS 为"无法计算"，严禁显示 0%。

## 三、CS测品规则

### 3.1 核心原则

1. 不看利润：不走 A/B/C/D，profit_level 为空
2. 不用测款成本解释利润：测款成本是"测品投入成本"，恒为负是正常现象
3. 库存/广告状态标签照常计算（库存广告问题对CS同样有效）

### 3.2 生命周期（固定两态，无空值）

| 阶段 | 条件 |
|---|---|
| 测品期 | 当前库存 > 0（口径=页面"当前库存"，每商品最新快照 available_stock） |
| 测品结束 | 当前库存 = 0 |

- 人工可改，白名单仅：测品期 / 测品结束（写四阶段值返回400）
- 已知边界：未进货的新CS品显示"测品结束"，人工可改
- 人工确认 > 系统判定

### 3.3 CS固定参数与公式

| 项 | 值 |
|---|---|
| WFS配送费 | 固定 $4（悦斯CS特例：采购¥200、头程¥1） |
| 平台扣点 | 0.15 |
| 单订单测品履约成本 | $5 |
| 测款成本 | 总销售额×0.85 − 广告费 − 测评成本(=总销售额) − 订单量×5 |
| 测品天数 | 首次广告日期 ~ 非WFS库存清零日 |

### 3.4 CS关注指标

测品天数、非WFS库存、累计销量、自然订单比例（自然单=总单-广告单）、
广告订单/销售额/占比、曝光、点击、CTR、CPC、CVR、ACOS、
自动广告表现/手动广告表现（按 fact_ads_keyword_daily.source_type 区分：
walmart_auto_csv=自动 / manual_kw=手动；CS第3期升级项）

## 四、预警体系汇总

### 4.1 problem_tags 全集（JSON数组，多标签并存）

| 类别 | 标签 |
|---|---|
| 利润 | 真实亏损、严重低毛利、低毛利风险、利润数据不足 |
| 库存 | 缺货风险、库存积压严重、有利润但库存积压、低利润压库存、近7天无销量 |
| 广告 | 广告浪费、广告占比偏高、广告无转化、广告无花费 |
| 生命周期 | 新品期、上升期、稳定期、清货期、缺上架时间 |

### 4.2 GPT 分析的问题分类与优先级

优先处理顺序（priority_problem_products 排序）：
真实亏损 > 断货风险 > 广告浪费 > 有库存不出单 > 库存周转慢

行级动作规则示例（GPT自动给出）：
- 库存为0但广告仍有花费 → 先降/停广告再补货
- 广告浪费且无自然单 → 整体转化差，先查Listing/价格/主图再调广告
- 广告浪费但有自然单 → 重点排查广告词、出价、匹配方式
- 低利润压库存 → 优先促销清库存，暂停补货，控制广告

### 4.3 页面双色高亮预警（产品管理页·系统生命周期列）

| 颜色 | 含义 | 应对 |
|---|---|---|
| 蓝色 | 人工已覆盖且系统判断未变（人工≠系统，基线一致） | 人工判断生效中，无需动作 |
| 红色 | 人工确认后系统判断发生了变化（系统≠确认时快照） | 提醒复核人工值是否仍然成立 |
| 无高亮 | 无人工值（跟随系统）或人工=系统 | — |

### 4.4 快照与滞后提示

- 状态字段为每日快照，数据可用日为 T-2（利润数据上游18:30生成T-2数据）
- GPT 输出会标注"截至 state_as_of 的状态"；最近两天的销售/广告正常统计，
  但不计入毛利判断（利润行尚未生成）

## 五、规则变更纪律

任何规则阈值/口径调整：先改本手册与 context/DATABASE_MAP 定稿 →
再改代码（buildProductBusinessState.ts 为唯一规则计算处）→
页面与 GPT 自动同步（一处计算，两处读取）。
禁止在前端或 GPT Instructions 里私改阈值造成口径分叉。
