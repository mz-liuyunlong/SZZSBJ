# old-system

本目录用于存放旧系统代码，只作为新系统重建时的只读参考。

允许：

- 读取旧系统代码
- 分析旧系统功能
- 总结旧系统页面、接口、数据库、定时任务
- 将分析结果写入 docs/old-system-analysis/

禁止在本目录中：

- 修改代码
- 开发新功能
- 修复旧 Bug
- 运行旧系统脚本
- 运行写入数据库的脚本
- 安装依赖
- 格式化旧代码
- 将旧代码直接复制到新系统
- 提交真实密钥、Token、Cookie、数据库密码、私钥或生产数据

目录说明：

```text
old-system/source/   旧系统源码，只读参考
old-system/reports/  旧系统交接报告，只读参考
